Today's Paper Review - Microsoft's SkillOpt

The success of AI agents relies on more than just the foundation model. It also depends on "skills": text documents defining the rules, tool calls, and strategies an agent must follow.

Unlike LLMs that undergo rigorous training, agent skills are usually generated once by prompting a model or edited by hand. Microsoft’s new SkillOpt changes this by treating skills as trainable artifacts that can be iteratively optimized.

Why It Matters

Since agent skills are critical for performance, the authors argue they should become trainable. A reliable way of automatically optimizing these text instructions could massively boost the reliability of agentic workflows deployed in production, without touching a single model weight.

SkillOpt High-Level Pipeline

( https://6da61843.click.kit-mail3.com/4zukre722waehpdxrz0ixh69vp4p9a5hg5xer/wnh2hghq29rr8nt7h3/aHR0cHM6Ly9haXBhcGVyc2FjYWRlbXkuY29tL3NraWxsb3B0Lw== )​
SkillOpt works by repeatedly running an agent on tasks and improving its skill file based on full execution traces.

Here’s the core loop:

* The agent attempts a batch of tasks using the current skill file.
* An LLM then analyzes the full trajectory including tool use, reasoning steps, and final output, and proposes edits to the skill. These edits can add new rules, remove outdated ones, or refine instructions.
* Each update is ranked and filtered (like a learning-rate control)
* Crucially, SkillOpt doesn’t blindly accept changes. Only changes that improve performance on a validation set are accepted.
* After each epoch, it reflects on broader patterns, what edit works, what is still unsolved, and updates a meta-skill for the next epoch.

The Neural Network Analogy

* The skill file acts like the model weights.
* Proposed edits act like gradients suggesting how those weights should change.
* The number of edits allowed per iteration functions like a learning rate.
* Validation acts as a safeguard, ensuring updates improve performance before they are accepted

The empirical results are remarkable. SkillOpt shows consistent improvement across 6 benchmarks spanning direct chat, Codex, and Claude Code environments. One of the highlights is on SpreadsheetBench, where it boosts GPT-5.5 from 41.8% to 80.7% accuracy.
