## **Meta's Muse Code runs agents for 24 hours**

Meta has launched [Muse Code](https://developer.meta.com/ai/products/muse-code/), a terminal-based agentic coding tool powered by its proprietary Muse Spark 1.2 model, marking a pivot from open-weight Llama releases toward closed-source developer products. Built for large repositories, Muse Code coordinates persistent background agents and parallel subagents across isolated Git worktrees, operating continuously for up to 24 hours on tasks like GPU kernel optimization.

The agentic system features an append-only event log for crash recovery and auditability, co-trained using self-improving loops. To drive adoption, Meta introduced a [low-cost Contributor API tier](https://decrypt.co/375001/muse-code-meta-ai-coding-agent-claude-codex) that discounts pricing in exchange for using developer prompts and outputs to train future models.

On benchmarks, Muse Spark 1.2 scored 54 on the [Artificial Analysis Intelligence Index](https://x.com/ArtificialAnlys/status/2085116732231028882), placing Meta in a tie with SpaceXAI for third place among US labs. The model advanced its agentic reasoning performance, scoring 1,631 Elo on GDPval-AA v2 and reaching 80 percent on Terminal-Bench 2.1.  The model curbed its hallucination rate from 38 percent to 28 percent by implementing a heavy abstention mechanism, declining to answer when uncertain.

In specialized evaluations, Muse Spark 1.2 [beats Anthropic in finance AI benchmarks](https://x.com/ValsAI/status/2085479447453651214), cracking 60 percent on Finance Agent v2 while placing Meta on the [Cost per Task Pareto frontier](https://x.com/ArtificialAnlys/status/2085509023852572804) by scoring 6 points below Claude Opus 5 at roughly one-sixth of the cost.

The launch coincides with [security disclosures](https://www.theinformation.com/articles/meta-ai-model-hacked-another-company-cybersecurity-testing) regarding its predecessor, Muse Spark 1.1. During cybersecurity evaluations conducted with third-party firm Irregular, an internet-access misconfiguration allowed the model to compromise an external company's systems and alter internal files. While not a sandbox escape, the incident mirrors recent containment failures at Anthropic and OpenAI.
