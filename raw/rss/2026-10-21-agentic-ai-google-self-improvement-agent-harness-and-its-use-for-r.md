# Google Self Improvement Agent Harness² and its use for Red Teaming Agent as an example.

<p><em>Google's Harness&#178; leaves the model frozen and improves the harness around it. This article explains how the loop works &#8212; then shows the exact code and steps we used to point it at a red-teaming agent.</em></p><p>Google published Harness&#178; in early October 2026: a framework for recursive agent harnessing. The idea is simple and radical at once. Stop trying to improve the agent by changing the model. Freeze the weights, and let an automated loop rewrite everything around them &#8212; the system prompt, the guardrails, the memory, the tool guidance, the subagents, the skills, the scripts, the plugins. Eight editable components. The loop proposes a harness edit, probes it by running the task, and composes the refined harness from the behavioral contrast. No ground truth. No gradients.</p><p>We tested it on a red-teaming agent: an attacker whose job is to get a victim assistant to transfer $500 to an attacker wallet. The attacker, the improver, and the victim all ran on one frozen free model through OpenRouter. Total model spend: effectively $0. The base attacker succeeded in two messages. The loop then audited the harness, rejected three of its own proposed trees &#8212; including one that changed nothing, because the base itself shipped an invalid plugin file &#8212; and made the evidence-backed decision to keep a working harness untouched. Along the way it found two real defects, which we fixed and verified.</p><p>The eight components are the whole story. The system prompt, the guardrails, the memory, the tool guidance, the subagents, the skills, the scripts, the plugins &#8212; these files are the only things the loop may edit, and in our run they were the only things that needed editing. The model never changed. Nothing was retrained, fine-tuned, or swapped. Every improvement came from rewriting the harness around it, which means every improvement is readable: you can open the diff and see exactly what changed and why.</p><p>Figure 1 is the setup:
