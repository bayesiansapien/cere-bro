# Agent commerce’s 7 layer stack, with case studies per layer

<p>Agent commerce is no longer a single-product race. Value, risk, and durable margin concentrate across seven stacked layers: Model, Data, Protocol, Identity and Hosting, Evaluation, Security and Compliance, and Ecosystem. </p><p>Visa&#8217;s October 2025 Trusted Agent Protocol release cites a 4,700% surge in AI-driven traffic to U.S. retail sites. Google ships Universal Commerce Protocol (UCP) for AI Mode and Gemini checkout. OpenAI and Stripe maintain Agentic Commerce Protocol (ACP) for agent checkout. </p><p>In September 2026 Amazon blocked Meta&#8217;s Muse agent from shopping Amazon.com without authorization. Builders who only optimize the model layer lose when portals cut access, protocols fork, or evaluation and security gates fail before the first paid order.</p><p>Today we cover:</p><ol><li><p><strong>The seven-layer map</strong> &#8212; where capability, commercial access, and accountability sit, and why security cuts across every layer.</p></li><li><p><strong>Layer 01 Model case studies</strong> &#8212; cheaper tokens, commerce-tuned open weights, and routers (OpenAI, Anthropic, Google, Meta Llama, Groq, Fireworks, OpenRouter, Portkey).</p></li><li><p><strong>Layer 02 Data case studies</strong> &#8212; clean catalogs, consented profiles, licensed portal data (Salsify, Akeneo, Inriver, Segment, LiveRamp, Snowflake clean rooms).</p></li><li><p><strong>Layer 03 Protocol case studies</strong> &#8212; payment rails, multi-standard bridges, MCP skills (Visa TAP, Mastercard Agent Pay, Stripe ACP, Google UCP/AP2/A2A, Anthropic MCP).</p></li><li><p><strong>Layer 04 Identity and Hosting case studies</strong> &#8212; verify, score, isolate (Visa TAP + Cloudflare, Skyfire, E2B, Daytona, Modal).</p></li><li><p><strong>Layer 05 Evaluation case studies</strong> &#8212; commerce regression and certification (Braintrust, LangSmith, Promptfoo/OpenAI, AIUC-1).</p></li><li><p><strong>Layer 06 Security case studies</strong> &#8212; guards, proofs, scored liability (Lakera/Check Point, Prompt Security, OWASP AIVSS and CSA).</p></li><li><p><strong>Layer 07 Ecosystem case studies</strong> &#8212; access deals, liability, standards seats (Amazon vs Meta Muse; OWASP, Linux Foundation, W3C).</p></li></ol>
