# A security researcher built a self-spreading worm that hides inside Word docs and hijacks Microsoft Copilot

<p><img alt="" class="attachment-full size-full wp-post-image" height="1152" src="https://the-decoder.com/wp-content/uploads/2026/07/microsoft_copilot_logo-2.png" style="height: auto; margin-bottom: 10px;" width="2048" /></p>
<p>        A security researcher has demonstrated a worm-like attack on Microsoft Copilot for Word: invisible prompt injections hidden in documents spread automatically into new files every time they're reused. Microsoft confirmed the issue but failed to fix it after 144 days and two attempts.</p>
