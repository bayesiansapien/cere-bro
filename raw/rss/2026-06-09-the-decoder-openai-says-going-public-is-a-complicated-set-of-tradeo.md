# OpenAI says going public is "a complicated set of tradeoffs" and is unsure about the timing

<p>        OpenAI has confidentially filed an S-1 registration with the SEC, taking the first formal step toward an IPO. There's no set timeline, and the company calls it "a complicated set of tradeoffs." Rival Anthropic recently filed its own IPO paperwork, which likely adds to the pressure.</p>
