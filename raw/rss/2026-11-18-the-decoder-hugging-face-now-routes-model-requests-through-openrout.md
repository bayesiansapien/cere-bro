# Hugging Face now routes model requests through OpenRouter for the best price or speed

<p><img alt="The purple OpenRouter logo and the Hugging Face emoji, connected by a cross, on a light background with a purple and yellow color gradient." class="attachment-full size-full wp-post-image" height="650" src="https://the-decoder.com/wp-content/uploads/2026/11/huggingface-openrouter-01-hero.jpg" style="height: auto; margin-bottom: 10px;" width="1300" /></p>
<p>        Hugging Face now routes language model requests through OpenRouter, which automatically selects the cheapest or fastest provider. Bring-your-own API keys for language models are going away. According to OpenRouter, the new routing cut capacity errors by 46 percent. Both partners face multibillion-dollar acquisitions.</p>
