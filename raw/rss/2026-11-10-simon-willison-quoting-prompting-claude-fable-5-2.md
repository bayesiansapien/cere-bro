# Quoting Prompting Claude Fable 5.2

<blockquote cite="https://platform.claude.com/docs/en/build-with-claude/prompt-engineering/prompting-claude-fable-5-2#say-who-owns-the-code"><p>Claude Fable 5.2 responds closely to what the prompt says about who owns the code it works on. In Anthropic’s testing on small coding tasks, when a prompt said nothing about ownership or presented the code base as someone else’s, the model tended to add to the existing structure, even when that repeated existing code. [...]</p>
<p>If you want the model to improve the structure as it works, say that the code is its own:</p>
<blockquote>
<p><code>This codebase is yours: what it's for and how it's built are your call, and you'll keep building on it.</code></p>
</blockquote>
<p>In Anthropic’s testing on small coding tasks, the model merged repeated code in about half of the tries with this sentence, and in under a tenth of the tries without it.</p></blockquote>
