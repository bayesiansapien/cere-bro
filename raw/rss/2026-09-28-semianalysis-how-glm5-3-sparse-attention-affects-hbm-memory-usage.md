# How GLM5.3 Sparse Attention Affects HBM Memory Usage

<h1><span>How Sparse Attention Affects DRAM/NAND Memory </span></h1><p><span>How does sparse attention affect the TAM of memory, including HBM and NAND? Sparse attention selects top-k most relevant tokens to attend to, reducing the memory consumption and bandwidth requirements during the core Scaled Dot-Production Attention (SDPA) operation. However, </span><strong><span>the efficiency improvement doesn&#8217;t directly translate to overall memory savings in practice</span></strong><span>. Concretely, the top-k selection operation typically requires the full context to be in HBM, so </span><strong><span>sparse attention doesn&#8217;t eliminate the memory capacity
