# AI coding agents still need human cleanup on nearly three out of four tasks in a real-world test

<p><img alt="" class="attachment-full size-full wp-post-image" height="670" src="https://the-decoder.com/wp-content/uploads/2026/11/co-design-bench-nano-banana-pro.jpg" style="height: auto; margin-bottom: 10px;" width="1200" /></p>
<p>        Alibaba's new coding-agent benchmark, Co-Design Bench, tests AI agents on real user requests that already tripped them up in practice. Even GPT-6 Astra, the top performer, fully solves only 26.4 percent of tasks. On older benchmarks, the same models score above 99 percent.</p>
