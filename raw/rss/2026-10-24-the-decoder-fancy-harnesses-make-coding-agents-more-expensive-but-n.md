# Fancy harnesses make coding agents more expensive but not better, study finds

<p><img alt="Color illustration of a spacesuit with a retro computer, cables, and a token power meter in the background." class="attachment-full size-full wp-post-image" height="1047" src="https://the-decoder.com/wp-content/uploads/2026/10/harness-buys-tokens-nano-banana-pro.jpg" style="height: auto; margin-bottom: 10px;" width="1920" /></p>
<p>        A controlled study shows that switching between coding-agent harnesses like Claude Code, OpenCode, or mini-SWE-agent barely moves pass rates more than rerunning the same setup. Cost per task, however, can triple, driven mainly by the system prompt that gets resent with every step.</p>
