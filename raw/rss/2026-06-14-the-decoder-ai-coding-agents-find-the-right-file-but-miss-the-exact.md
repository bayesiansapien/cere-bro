# AI coding agents find the right file but miss the exact lines that matter, study shows

<p><img alt="A neon-colored code editor with highlighted code blocks and a magnifying glass in a crosshair, symbolizing code analysis and search." class="attachment-full size-full wp-post-image" height="1047" src="https://the-decoder.com/wp-content/uploads/2026/06/swe-explore-nano-banana-pro.jpg" style="height: auto; margin-bottom: 10px;" width="1920" /></p>
<p>        AI coding agents like Claude Code or Codex reliably find the right file but miss most of the critical lines within it. The new SWE-Explore benchmark is the first to test code search separately from the actual repair, and it shows that without enough context, even the best fix will fail.</p>
