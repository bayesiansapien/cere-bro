# Anthropic’s Claude Code Reigns Despite Rising Interest in Codex, Open-Source Models

<p><a href="https://www.theinformation.com/org-charts/anthropic">Anthropic</a> is facing growing competition and customer skepticism over the <a href="https://www.theinformation.com/articles/anthropic-changes-pricing-bill-firms-based-ai-use-amid-compute-crunch">lofty prices</a> of AI tools. But the dominance of its blockbuster Claude Code product is proving hard to shake.</p>

<p>Companies moved en masse to Claude Code between the end of 2025 and the early months of 2026, in many cases eroding the positions of Microsoft’s GitHub Copilot and AI coding tool provider Cursor. In recent months, <a href="https://www.theinformation.com/articles/ai-customers-lowering-anthropic-openai-bills">costs for Anthropic’s customers have surged</a> with its shift to usage-based pricing, while rival <a href="https://www.theinformation.com/org-charts/openai">OpenAI</a> has built Codex into a more formidable competitor and open-source models from China have grown significantly more capable.</p>

<p>Still, even as they look for ways to contain costs, many enterprises have chosen to stick with Claude Code.</p>
