# Muru

<p><strong><a href="https://github.com/muruhq/muru">Muru</a></strong></p>
Graham Dumpleton started <a href="https://modwsgi.readthedocs.io/">mod_wsgi</a> 20 years ago, and has been thinking about the ideal way to serve Python web applications in production ever since.</p>
<p>Muru is his new, AI-assisted Rust server that aims to provide the best possible tools for running ASGI and WSGI Python apps both in development and production.</p>
<p>As <a href="https://simonwillison.net/2026/Sep/11/wrapture/">he did with wrapture</a>, he's been publishing an extraordinarily detailed account of the project as he works on it - as part of his development process.</p>
