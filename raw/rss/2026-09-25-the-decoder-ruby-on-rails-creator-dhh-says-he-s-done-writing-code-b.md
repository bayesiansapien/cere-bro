# Ruby on Rails creator DHH says he's done writing code by hand

<p><img alt="" class="attachment-full size-full wp-post-image" height="720" src="https://the-decoder.com/wp-content/uploads/2026/09/dhh_programmier_ruecktritt.png" style="height: auto; margin-bottom: 10px;" width="1280" /></p>
<p>        David Heinemeier Hansson, creator of Ruby on Rails, has quit writing code by hand after 25 years. He says he hasn't typed a single line since March 2026. "English is a better programming language than Ruby," DHH told the audience at Rails World 2026. Just a year ago, he was pushing back against AI coding. Now he calls it "the biggest thing that has happened in the history of computing."</p>
