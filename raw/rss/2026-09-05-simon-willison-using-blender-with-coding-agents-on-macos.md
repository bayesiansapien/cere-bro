# Using Blender with coding agents on macOS

<p><strong>TIL:</strong> <a href="https://til.simonwillison.net/llms/blender-coding-agents-macos">Using Blender with coding agents on macOS</a></p>
        <p>I've been having fun with Blender in ChatGPT Codex on my Mac recently. Getting it to work with coding agents is really easy: install the full Mac application from <a href="https://www.blender.org">blender.org</a> and run a prompt like this:</p>
<blockquote>
<p><code>Use the already install /Applications/Blender to render a scene of a pelican riding a bicycle</code></p>
</blockquote>
<p>In this case I followed that up with these two prompts:</p>
<blockquote>
<p><code>OK add a background and a lot of flair</code></p>
</blockquote>
<p>Then:</p>
<blockquote>
<p><code>OK make it a whole lot better</code></p>
</blockquote>
<p>And got this image, generated <a href="https://github.com/simonw/gpt-6-astra-blender-pelican-bicycle/blob/main/work/pelican_final.py">using Blender's Python API</a>:</p>
