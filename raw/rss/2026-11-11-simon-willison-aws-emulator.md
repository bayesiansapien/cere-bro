# aws-emulator

<p><strong><a href="https://github.com/aws/aws-emulator">aws-emulator</a></strong></p>
Finally, an official emulator from AWS to run tests against a local clone of their many different services without having to provision a paid API key to do so.</p>
<p>It's written in Rust by a huge swarm of agents - 29,684 commits in the first three weeks of the project. Swaminathan (Swami) Sivasubramanian wrote about <a href="https://www.allthingsdistributed.com/2026/11/aws-emulator-and-the-engineers-job-when-agents-write-the-code.html">how it came to be</a> in a guest post on Werner Vogels' blog.</p>
<p>It currently requires Docker to run on macOS or Windows. I'm hoping they fix that in the future - it would be great if you could download a single binary and use that as part of a standard test suite in other languages and on other platforms.
