# Donating Agent Skills to the Agentic AI Foundation

<p><strong><a href="https://www.anthropic.com/news/donating-agent-skills-to-the-agentic-ai-foundation">Donating Agent Skills to the Agentic AI Foundation</a></strong></p>
News today from Anthropic:</p>
<blockquote>
<p>We’re committed to keeping Agent Skills open, community-driven, and vendor-neutral. Today, we are donating the standard to the Agentic AI Foundation (AAIF) under the Linux Foundation, <a href="https://www.anthropic.com/news/donating-the-model-context-protocol-and-establishing-of-the-agentic-ai-foundation">which we co-founded</a> with Block and OpenAI last year, and to which we donated the Model Context Protocol (MCP).</p>
</blockquote>
<p>I'm pleased to note I called this one <a href="https://simonwillison.net/2025/Dec/19/agent-skills/">last December</a>, when Anthropic first declared skills to be an "open standard":</p>
<blockquote>
<p>I wouldn't be surprised to see this end up <a href="https://simonwillison.net/2025/Dec/9/agentic-ai-foundation/">in the AAIF</a>, recently the new home of the MCP specification.</p>
</blockquote>
