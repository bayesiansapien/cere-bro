# Perplexity's new Monitor API turns web search from a one-off query into a nonstop watchdog

<p><img alt="Bright blue, geometric Perplexity AI logo on a dark background" class="attachment-full size-full wp-post-image" height="768" src="https://the-decoder.com/wp-content/uploads/2026/06/Perplexity-Logo-Silhouette-Nano-Banana-Pro.jpg" style="height: auto; margin-bottom: 10px;" width="1376" /></p>
<p>        Perplexity is launching a Monitor API that searches the web on a schedule and alerts agents via webhook only when relevant changes occur. Its own decision model filters out unimportant results. For Perplexity, the API is part of a broader strategy to stand out from an increasingly interchangeable chatbot business through developer tools.</p>
