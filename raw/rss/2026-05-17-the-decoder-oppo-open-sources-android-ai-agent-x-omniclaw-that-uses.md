# Oppo open-sources Android AI agent X-OmniClaw that uses your camera, screen, and voice without leaving the phone

<p><img alt="Collage-like editorial illustration of a transparent smartphone with map cutouts, black and white street scenes, audio waveform, media player controls and text cards floating around it in neon blue, yellow and red color fields." class="attachment-full size-full wp-post-image" height="1047" src="https://the-decoder.com/wp-content/uploads/2026/05/x-omniclaw-smartphone-agent-nano-banana-pro.jpg" style="height: auto; margin-bottom: 10px;" width="1920" /></p>
<p>        Oppo's Multi-X team released X-OmniClaw, an open-source agent that runs directly on Android devices and combines camera, screen, and voice to handle tasks in real apps. Instead of relying on cloud copies of the phone, the system uses local sensors; cloud compute only kicks in for reasoning. Tap paths get cloned as reusable skills, so the agent can jump straight to deeply nested app pages via deeplink next time around.</p>
