# How Firms Like Coinbase Are Building Coding Agents to Complement Anthropic's Claude Code

<p>Coinbase and some other tech-savvy firms such as Shopify and Ramp have built their own AI coding agents for internal use, giving their employees an alternative to pricey options from firms like Anthropic and OpenAI.</p><p>Coinbase, the cryptocurrency exchange, built an AI coding agent called Forge, which launched to all of its engineers in April of this year, senior director of engineering Chintan Turakhia told me. Engineers can access the coding agent through Slack, Github, and its own web user interface.</p><p>Usage of Forge is growing fast internally and has resulted in cost savings, said Turakhia, although he declined to be specific.</p>
