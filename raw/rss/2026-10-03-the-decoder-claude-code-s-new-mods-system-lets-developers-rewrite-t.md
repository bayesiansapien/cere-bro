# Claude Code's new Mods system lets developers rewrite the AI coding tool from the inside

<p>        Anthropic is adding a "Mods" system to Claude Code, essentially middleware that runs directly inside the tool. Developers can use JavaScript or TypeScript to reshape the interface and behavior, adding custom panels, intercepting tool calls, or wiring up new commands.</p>
