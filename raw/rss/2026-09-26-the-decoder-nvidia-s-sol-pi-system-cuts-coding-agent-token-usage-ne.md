# Nvidia's SoL-Pi system cuts coding agent token usage nearly in half by optimizing the harness

<p><img alt="Stylized illustration of modular AI modules with intertwined cables and a glowing data stream" class="attachment-full size-full wp-post-image" height="1047" src="https://the-decoder.com/wp-content/uploads/2026/09/solpi-agent-harness-optimization-nano-banana-pro.jpg" style="height: auto; margin-bottom: 10px;" width="1920" /></p>
<p>        SoL-Pi cuts coding agents' token usage by up to 49 percent with little change in performance by optimizing the control layer between the model and its environment. A research agent tested 152 approaches across more than 3,000 runs to develop the system, though the gains were smaller on other benchmarks.</p>
