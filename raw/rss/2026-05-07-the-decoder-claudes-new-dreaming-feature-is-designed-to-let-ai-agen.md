# Claude's new "Dreaming" feature is designed to let AI agents learn from their mistakes

<p><img alt="" class="attachment-full size-full wp-post-image" height="768" src="https://the-decoder.com/wp-content/uploads/2026/05/anthropic_dreaming-2.png" style="height: auto; margin-bottom: 10px;" width="1376" /></p>
<p>        Anthropic is adding "Dreaming" to Claude Managed Agents, an asynchronous process that reviews past agent sessions, cleans up duplicate or outdated memory entries, and distills new insights. Along with Outcomes and Multiagent Orchestration, now both in public beta, the updates are designed to help AI agents learn and improve across sessions.</p>
