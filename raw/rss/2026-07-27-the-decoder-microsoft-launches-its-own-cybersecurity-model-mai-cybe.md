# Microsoft launches its own cybersecurity model MAI-Cyber-1-Flash but still depends on OpenAI for the toughest tasks

<p><img alt="" class="attachment-full size-full wp-post-image" height="608" src="https://the-decoder.com/wp-content/uploads/2026/06/microsoft_logo_red_pink.png" style="height: auto; margin-bottom: 10px;" width="1088" /></p>
<p>        Microsoft introduces MAI-Cyber-1-Flash, a compact security model that scores 96 percent on the CyberGym benchmark when embedded in its MDASH multi-agent system. Microsoft says costs should drop by 50 percent compared to pure frontier models, since only tough cases get passed to GPT-5.4. For complex reasoning, Microsoft still relies on OpenAI.</p>
