# OpenAI open-sources Codex Security CLI to help developers find and fix vulnerabilities from the command line

<p><img alt="" class="attachment-full size-full wp-post-image" height="1152" src="https://the-decoder.com/wp-content/uploads/2026/07/openai_red_Logo.png" style="height: auto; margin-bottom: 10px;" width="2048" /></p>
<p>        OpenAI has released Codex Security CLI, an open-source tool that automatically detects and fixes vulnerabilities in code repositories. Previously known internally as "Aardvark," the system has already helped fix more than 3,000 critical security flaws, according to OpenAI. It competes directly with Anthropic's Claude Security, as both AI companies race to match the growing automation of cyberattacks with AI-powered defense.</p>
