# Z.ai follows OpenAI into loop transformer territory with its new 750B flagship model

<p><img alt="White Zhipu AI logos in a diagonal pattern on a black background; modern branding design." class="attachment-full size-full wp-post-image" height="1072" src="https://the-decoder.com/wp-content/uploads/2026/06/zhipu-ai-logo-wall-nano-banana-pro.jpg" style="height: auto; margin-bottom: 10px;" width="1920" /></p>
<p>        Z.ai is moving its flagship GLM-5.4 model to a loop architecture in which 28 layers run twice, which the company says lets the 750-billion-parameter model match models with 2 to 3 trillion parameters. Benchmark scores are only available for a smaller 30B test model so far, and Z.ai is positioning GLM-5.4 as the start of "Generalized Coding," where code also generates videos, games, and CAD models.</p>
