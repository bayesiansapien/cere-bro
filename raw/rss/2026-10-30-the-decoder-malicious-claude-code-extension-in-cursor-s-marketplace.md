# Malicious Claude Code extension in Cursor's marketplace attempted remote access and data theft

<p><img alt="Logo of Cursor.ai" class="attachment-full size-full wp-post-image" height="800" src="https://the-decoder.com/wp-content/uploads/2024/08/cursor_AI_logo.png" style="height: auto; margin-bottom: 10px;" width="1200" /></p>
<p>        A tampered Claude Code extension was live on the Cursor marketplace for about 11 hours, affecting up to 5,000 users. It tried to steal user data and set up remote access. Cursor took the entire marketplace offline and reinstated it after confirming there was no further risk.</p>
