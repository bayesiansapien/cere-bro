# Anthropic warns Claude Mythos Preview finds bugs faster than developers can patch them

<p><img alt="" class="attachment-full size-full wp-post-image" height="768" src="https://the-decoder.com/wp-content/uploads/2026/05/glasswing_claude.png" style="height: auto; margin-bottom: 10px;" width="1376" /></p>
<p>        Anthropic's AI model Claude Mythos Preview, working with about 50 partners as part of Project Glasswing, has found over 10,000 critical vulnerabilities in system-critical software. The bugs are piling up faster than anyone can patch them. Anthropic warns this creates a high-risk transition period and says no company, itself included, has built safeguards strong enough to prevent misuse of these models.</p>
