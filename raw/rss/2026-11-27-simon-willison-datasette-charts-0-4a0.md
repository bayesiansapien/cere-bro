# datasette-charts 0.4a0

<p><strong>Release:</strong> <a href="https://github.com/datasette/datasette-charts/releases/tag/0.4a0">datasette-charts 0.4a0</a></p>
        <p>The new datasette-charts plugin has its own plugin hook to allow other plugins to define new chart types, but I hadn't actually used it for anything yet. I had Claude Opus 5.5 build an experimental plugins just to try out the hook and it came up with a bunch of friction points in the design. This release addresses those, which should make building additional chart plugins a whole lot more ergonomic.</p>
<p>I've also added a website for the plugin, at <a href="https://charts.datasette.io/">charts.datasette.io</a>. The new website includes a <a href="https://charts.datasette.io/docs/plugins/">tutorial for plugin authors</a>, and <a href="https://charts.datasette.io/gallery/">a gallery</a> showing all of the core charts and annotations, each one linking to an interactive demo on <a href="https://lite.datasette.io/">Datasette Lite</a>.</p>
