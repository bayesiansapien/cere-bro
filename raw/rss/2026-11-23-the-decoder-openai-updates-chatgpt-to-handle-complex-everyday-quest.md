# OpenAI updates ChatGPT to handle complex everyday questions, web searches, and images more reliably

<p><img alt="" class="attachment-full size-full wp-post-image" height="1440" src="https://the-decoder.com/wp-content/uploads/2026/11/openai_chatgpt_pattern.png" style="height: auto; margin-bottom: 10px;" width="2560" /></p>
<p>        OpenAI is making GPT-6.2 Sol the new default model in ChatGPT's chat tab, rolling it out worldwide. In internal tests, image understanding jumped from 47.4 to 71.7 percent, and the model now handles difficult instructions correctly 78.1 percent of the time. It also sticks to safety policies more consistently.</p>
