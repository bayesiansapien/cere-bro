# Microsoft's SkillOpt boosts GPT-5.5 by using nothing but a trained Markdown file

<p><img alt="An abstract collage of grids, arrows, and paper fragments symbolizes neural data flow and training." class="attachment-full size-full wp-post-image" height="1025" src="https://the-decoder.com/wp-content/uploads/2026/06/skillopt-markdown-neural-training-nano-banana-pro.jpg" style="height: auto; margin-bottom: 10px;" width="1920" /></p>
<p>        Microsoft and three Chinese universities have developed SkillOpt, a method that optimizes instruction documents for AI agents using principles from traditional model training. A simple Markdown file is enough to boost GPT-5.5 by about 23 points on procedural tasks, and the same file transfers across models and agent environments like Codex and Claude Code.</p>
