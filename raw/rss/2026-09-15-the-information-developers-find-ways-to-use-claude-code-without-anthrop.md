# Developers Find Ways to Use Claude Code Without Anthropic Models

<p><b>Boris Cherney</b>, the head of <b>Anthropic’s</b> coding tool <b>Claude Code</b>, last month found himself in the middle of an online spat that highlighted how some developers are finding workarounds to using Claude Code with cheaper non-Anthropic models, including those of rival <b>OpenAI</b>, to save costs.</p><p>Developer <b>Alex Getman</b> used a proxy made up of lines of code to connect Claude Code to OpenAI’s<b> GPT-5.6 Sol</b>. Fifteen minutes after Getman typed the first coding requests into Claude, Anthropic shut down the account, he said.&nbsp;</p><p>Claude Code is popular because it comes with all the tools assembled to read and run files, search codebases and run tasks in parallel. But it doesn’t need to run on Anthropic models. And developers are saving money by using cheaper models with the Claude Code harness. For that reason, Getman’s posts <a href="https://x.com/alexgetmancom/status/2086092971024253117">about the ban</a> drew a million views within hours.&nbsp;</p>
