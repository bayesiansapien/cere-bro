# Adobe is testing how well AI agents can use editing tools like a Photoshop professional would

<p><img alt="" class="attachment-full size-full wp-post-image" height="1152" src="https://the-decoder.com/wp-content/uploads/2026/11/adobe_logo-2.png" style="height: auto; margin-bottom: 10px;" width="2048" /></p>
<p>        Adobe Research and UC San Diego built EditAgent, an AI system that edits images more like a Photoshop pro. Instead of retrying the same general-purpose editor over and over, the agent picks the right specialized tool for each task and lets a standard language model choose the best result based on measured image data. The approach works, but it needs about ten times the compute.</p>
