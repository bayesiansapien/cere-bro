# Why OpenAI’s DevDay Looked Like Catch-Up

<p>While the rest of us were distracted by details within <b>Anthropic’s</b>&nbsp;<a href="https://www.theinformation.com/briefings/anthropics-confidential-filing-reveals-customer-concentration">IPO filing</a> and <b>OpenAI’s</b> <a href="https://www.theinformation.com/briefings/openai-early-talks-raise-30-billion-ipo">plans to raise $30 billion</a> in a new round that could value it around $1.4 trillion, app developers on Tuesday flooded to San Francisco’s Fort Mason for OpenAI’s annual developer conference, where it made a flurry of new product and feature announcements.</p><p>All in all, <b>OpenAI’s DevDay</b> felt a bit reactionary. Take<b> “Dots,”</b> an always-on or persistent agent product—which we <a href="https://www.theinformation.com/newsletters/ai-agenda/openai-develops-features-counter-grok-bot-mulls-response-metas-muse">broke</a> news about earlier this month—that promises to automate complex processes like turning customer feedback into improvements for an app or filling out invoices for employees.&nbsp;</p><p>In case you’re counting, this is OpenAI’s fifth attempt to launch an agent product, counting past tries like <b>Operator</b>, <b>Deep Research</b>, <b>ChatGPT Agent</b> and <b>ChatGPT Work</b>. The company said that this time was different, though, because of how good frontier AI like Astra has become (and they might be right!).&nbsp;</p><p>Dots looks similar to recent breakout agent products like <b>Instinct</b>, <b>Meta Platforms’ Muse</b> and <b>SpaceX’s Grok Bot</b>, which allow people to talk to agents through text and calls. To be fair, though, OpenAI’s version felt distinctly productivity- and work-focused compared to some of these other examples, especially with features like having Dots work together to create documents and presentations. (Separately, can anyone tell me how to test out all these different agent products? I’m personally overwhelmed.)</p>
