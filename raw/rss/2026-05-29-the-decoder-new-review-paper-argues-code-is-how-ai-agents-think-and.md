# New review paper argues code is how AI agents think and act, not just what they produce

<p><img alt="Four modular code agents on a rail network orbit a luminous data sphere in front of a circuit board pattern" class="attachment-full size-full wp-post-image" height="1025" src="https://the-decoder.com/wp-content/uploads/2026/05/Code-Agent-Harness-Nano-Banana-Pro.jpg" style="height: auto; margin-bottom: 10px;" width="1920" /></p>
<p>        A new review paper argues that the real bottleneck for autonomous AI agents isn't the language model itself but the software layer wrapped around it. Tools, memory, testing, and permission boundaries turn a stateless model into a working agent. Deepseek is already building a dedicated "Harness" team in Beijing with a core formula that confirms the thesis: model plus harness equals AI agent.</p>
