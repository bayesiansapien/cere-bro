# OpenAI's new Agents API gives developers the infrastructure behind Codex and ChatGPT

<p><img alt="" class="attachment-full size-full wp-post-image" height="768" src="https://the-decoder.com/wp-content/uploads/2026/09/openai_logo_astra-1.png" style="height: auto; margin-bottom: 10px;" width="1376" /></p>
<p>        OpenAI is releasing the Agents API as a public beta. It lets developers build cloud agents that run autonomously for hours, execute code, and hand off tasks to sub-agents. There are no extra fees beyond token usage. Cloudflare, Vercel, and Oracle offer additional sandbox environments.</p>
