# Anthropic's Message Threads cut time to first token by 35 percent for long conversations

<p><img alt="" class="attachment-full size-full wp-post-image" height="768" src="https://the-decoder.com/wp-content/uploads/2026/08/claude_logo-1.png" style="height: auto; margin-bottom: 10px;" width="1376" /></p>
<p>        Anthropic released Message Threads for the Messages API. Instead of resending the entire conversation with every turn, agents now only transmit what's changed. For requests between 500,000 and one million tokens, time to first token drops by about 35 percent.</p>
