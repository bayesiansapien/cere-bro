# Multi-Agent vs. Single-Agent AI: Which Should You Use? The Evidence May Surprise You

<p>A single-agent system using a 5-sample majority vote outperforms automatic multi-agent setups when inference costs are held equal. Salesforce Research tested six automatic multi-agent frameworks across four models and five benchmarks and found that these systems cost up to 10&#215; more than chain-of-thought with self-consistency (CoT-SC) &#8212; and still scored lower.</p><p>Sakana AI took a different approach. They ran 70 research campaigns using pre-written evaluation rubrics, then systematically ablated each component to isolate what actually worked.</p><p>Datadog showed another path: by training a specialized model on a curated set of real incidents, they matched the performance of GPT-6.1 Sol High and Claude Opus 5.5 High at 3&#8211;8&#215; lower estimated inference cost.</p><p>Together, these results point to a simple standard: if an agent system can&#8217;t demonstrate that it changes the answer &#8212; and justify the cost of doing so &#8212; it probably shouldn&#8217;t be used.
