# Game Boy Color on My Conference Badge

<p><strong><a href="https://spf13.com/p/game-boy-color-on-my-conference-badge/">Game Boy Color on My Conference Badge</a></strong></p>
I'm at GitHub Universe this week and, <a href="https://simonwillison.net/2025/Oct/28/github-universe-badge/">similar to last year</a>, the conference badge is a full-blown color screen computer.</p>
<p>I've been hacking around with it again, and then I ran into with Steve Francia... who worked with Gemini to get a <a href="https://spf13.com/p/zelda-on-my-conference-badge/">full NES emulator</a> working on it, and then went a step further and deployed an emulator for both the Game Boy and the Game Boy Color.</p>
<p>Which means, if you can obtain the ROM, you can run <a href="https://en.wikipedia.org/wiki/The_Legend_of_Zelda:_Link%27s_Awakening">The Legend of Zelda: Link's Awakening</a> on your conference badge!</p>
<p><img alt="Photo of the badge running Zelda, in full color, with visible touch buttons below the screen." src="https://static.simonwillison.net/static/2026-10-27/IMG_9339.jpeg" /></p>
<p>A neat feature of the badge is that you can turn it upside down and then use game controller touch buttons that are built into the badge body.
