# Why AI-Written Software Needs a Flight Simulator

<p>As companies create more applications using AI, corporate officers say demand is rising for a new type of software that stress-tests those apps, simulating how they handle network problems and other disasters that humans may not think to test for—including cyberattacks by rogue AIs.</p><p>Luis Chávez, CTO of coding assistant provider Replit, says his company uses an AI-assisted software known as a deterministic simulator, a kind of flight simulator for software. The deterministic part refers to how the simulator lets companies run the same disaster test again and again so they can try out different fixes for bugs that crop up during network failures or hacking attempts.</p><p>Traditional stress-testing methods rely on developers guessing every potential problem that may arise. Merely using today’s AI models to evaluate code often produces false alarms or fake warnings, corporate executives say.</p>
