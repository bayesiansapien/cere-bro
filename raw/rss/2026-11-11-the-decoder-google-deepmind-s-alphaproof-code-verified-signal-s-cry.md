# Google Deepmind's AlphaProof Code verified Signal's cryptographic core in four weeks instead of years

<p><img alt="" class="attachment-full size-full wp-post-image" height="768" src="https://the-decoder.com/wp-content/uploads/2026/11/deepmind_alphaproof.png" style="height: auto; margin-bottom: 10px;" width="1376" /></p>
<p>        Google Deepmind's AlphaProof Code mathematically verified Signal's cryptographic core code in four weeks, a process that typically takes years. AI agents powered by Gemini Carbon wrote more than six million lines of proof code and flagged only about one percent for human review. Deepmind plans to extend the method to critical infrastructure like power grids and medical devices.</p>
