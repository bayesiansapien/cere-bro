# OpenAI models now available on Amazon Web Services

<p><img alt="" class="attachment-full size-full wp-post-image" height="1125" src="https://the-decoder.com/wp-content/uploads/2026/06/aws-open-ai-amazon-news-jp-042426.jpeg" style="height: auto; margin-bottom: 10px;" width="2000" /></p>
<p>        OpenAI is making GPT-5.5, GPT-5.4, and Codex available through Amazon Bedrock at the same prices as OpenAI's own platform. The models run in commercial and government AWS regions but are limited to the US for now. Usage counts toward existing AWS contracts.</p>
