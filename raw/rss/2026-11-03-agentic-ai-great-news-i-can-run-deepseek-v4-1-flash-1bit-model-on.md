# Great News! I can run DeepSeek-V4.1-Flash 1bit model on a Single DGX Spark

<p>I have deploed DeepSeek-V4.1-Flash locally on a single NVIDIA DGX Spark and got <strong>18.10 generation tokens per second</strong> while maintaining 116.8 GB of model weights resident in unified memory. Thanks, and DeepSeek. </p><p>This architecture pairs a 552B parameter Mixture-of-Experts backbone (1-bit quant.) with a 196B parameter Engram memory table within the 128 GB memory boundary of the NVIDIA Grace Blackwell GB10 system-on-chip.</p><p>Production deployment scripts, compilation containers, client configuration files, and an agent red-teaming evaluation harness are published in the companion GitHub repository.
