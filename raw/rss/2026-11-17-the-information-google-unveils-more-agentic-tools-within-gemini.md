# Google Unveils More Agentic Tools Within Gemini

<p>Google has announced updates to Gemini, called Tasks, that will give it more agentic features, comparable to tools already released by Meta with Muse and OpenAI with Dots. The Task features will be free.</p> <p>Gemini will now be able to call businesses, make purchases, and read and send emails, ...</p>
