# OpenAI launches Decisions API that reduces complex evaluations to yes, no, or pick one

<p><img alt="" class="attachment-full size-full wp-post-image" height="768" src="https://the-decoder.com/wp-content/uploads/2026/09/openai_logo_astra-1.png" style="height: auto; margin-bottom: 10px;" width="1376" /></p>
<p>        OpenAI's new Decisions API classifies text and images about ten times faster than the Responses API, returning yes/no probabilities, category picks, or scale ratings for $0.10 per million input tokens. The company also cut its paid API tiers from five to three.</p>
