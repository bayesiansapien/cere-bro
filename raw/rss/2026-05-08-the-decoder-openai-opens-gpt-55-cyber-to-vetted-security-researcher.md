# OpenAI opens GPT-5.5-Cyber to vetted security researchers

<p><img alt="" class="attachment-full size-full wp-post-image" height="768" src="https://the-decoder.com/wp-content/uploads/2026/04/gpt-55_title.png" style="height: auto; margin-bottom: 10px;" width="1376" /></p>
<p>        OpenAI is releasing GPT-5.5-Cyber, a model variant that rejects far fewer security requests and even actively executes exploits against test servers. Access is limited to verified defenders of critical infrastructure, including partners like Cisco, CrowdStrike, and Cloudflare. The model competes directly with Anthropic's Mythos Preview.</p>
