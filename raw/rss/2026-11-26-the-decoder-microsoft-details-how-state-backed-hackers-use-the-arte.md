# Microsoft details how state-backed hackers use the ARTEX AI framework to automate cyberattacks

<p><img alt="" class="attachment-full size-full wp-post-image" height="768" src="https://the-decoder.com/wp-content/uploads/2026/10/microsoft_human_touch.png" style="height: auto; margin-bottom: 10px;" width="1376" /></p>
<p>        Microsoft has published the technical architecture of ARTEX, an AI framework in wide use since July 2026 that runs cyberattacks with specialized agents and almost no human involvement. State-backed groups from China and North Korea, along with criminal organizations, are already using the system. Microsoft recommends deception techniques like honeypots and faked success signals as defenses, but how long those will hold up against agents that learn and adapt remains an open question.</p>
