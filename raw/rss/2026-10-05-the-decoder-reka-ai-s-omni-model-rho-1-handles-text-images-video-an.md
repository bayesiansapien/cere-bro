# Reka AI's omni-model Rho-1 handles text, images, video, and robot control in a single model

<p><img alt="" class="attachment-full size-full wp-post-image" height="1152" src="https://the-decoder.com/wp-content/uploads/2026/10/rho1_images.png" style="height: auto; margin-bottom: 10px;" width="2048" /></p>
<p>        Reka AI's Rho-1 is a 19-billion-parameter omni-model that processes and generates text, images, video, and robot control actions in a single neural network. Trained on 320 H100 GPUs in about three months, it uses a fraction of the compute today's top models need. Instead of routing tasks to specialized systems, Rho-1 runs all modalities as tokens in one shared context window.</p>
