## Architecture & Optimization Mechanics
- **Subscription arbitrage is a pricing artifact, not an efficiency fact.** API-equivalent value = (plan token allowance × list API price) / plan price. A 5x gap means Anthropic subsidizes heavy agentic use or prices its API high relative to serving cost. It does not mean Claude models are 5x cheaper to serve. Routing decisions on owned infrastructure should use measured $/solved-task, not plan economics.
- **Cache-inclusive token counts hide the real cost.** "5B tokens for 40K credits" is meaningless until it is split into cached vs uncached input and output. Agentic coding traces are often 80 to 95% cache hits, and cached input runs ~10 to 20x cheaper. The same logic drives the Claude Code cache mod: once the 5-minute TTL expires, the next turn reprocesses the full prefix at full price. For long sessions, prefix-cache hit rate is the biggest single cost lever.
- **50 tok/s default decode is a serving-policy change, not a model change.** Raising default speed on the same weights most likely means smaller batch per replica, more speculative decoding, or a re-shard. Either way OpenAI is buying latency with GPU-hours, which fits the "efficiency so users get more usage" framing only if paired with a cheaper model (hence the GPT-Next expectation).
- **Beam's 501B/23B (~4.6% active) ratio** is in the DeepSeek/Kimi sparsity class. Per-token compute is comparable to a ~23B dense model, but you still have to hold ~500B params in memory: ~1 TB in BF16, ~250 GB at INT4. That is a multi-GPU expert-parallel deployment, not a single node unless quantized aggressively.
- **Statistical text watermarks bias token sampling.** That interacts directly with speculative decoding acceptance rates and with distillation. Student models trained on watermarked teacher outputs can inherit the signal, so watch for it in distillation data from EU-served endpoints.
