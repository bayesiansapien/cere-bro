## TL;DR
Payward (Kraken) has successfully integrated an "agentic" code governance layer powered by **OpenAI Codex**, accelerating their release cycles by 40%. By deploying a fleet of **50 concurrent AI agents** to handle first-pass reviews of Merge Requests (MRs) in their 15M+ line monorepo, Kraken has moved from traditional CI/CD to a "Continuous Compute" model where agents proactively manage code quality, security, and integration logic.

## Key Takeaways
- **Agentic MR Review:** A decentralized fleet of 50 agents reviews code changes simultaneously, identifying logic flaws and security vulnerabilities before human engineers intervene.
- **Continuous Compute:** Kraken has transitioned to an "always-on" infrastructure where agents proactively rebase branches and "fix forward," significantly reducing merge latency.
- **Inference as a Core Primitive:** Payward's AI infrastructure team is building a unified layer to deliver personalized, inference-driven user experiences across all financial products.
- **Confidence-Based Releases:** The system allows for autonomous releases if a consensus is reached among the agent fleet, provided the changes pass a "deterministic structural pause" for safety-critical logic.

## Architecture & Optimization Mechanics
- **Model Context Protocol (MCP):** The agents utilize a built-in MCP server to interact with Kraken’s internal tools, including a "paper trading" engine for verifying financial logic in real-time.
- **Compositional Reasoning:** Unlike simple LLM-assisted linting, the Codex agents employ compositional reasoning to understand dependencies across the 15M LOC monorepo, a scale that traditionally causes context-window saturation in standard RAG implementations.
- **Agent Identity & Security:** Utilizing **Auth0’s "Auth for AI Agents,"** Payward treats each of the 50 agents as a cryptographically verified non-human identity with short-lived, task-specific permissions.
- **OWASP Agentic AI Top 10:** The review agents are specifically tuned to catch "excessive agency" and "unauthorized tool call" risks, aligning with the 2026 standards for secure agentic systems.
