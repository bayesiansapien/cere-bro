## Architecture & Optimization Mechanics
- **Idle compaction is cache economics.** Anthropic's default prompt-cache TTL is 5 minutes (1h optional, at a higher write cost). A resumed long session with an expired cache re-prefills the full context at uncached price. Compacting before expiry means the summarization call itself hits a warm cache, and the resumed session prefills only the summary. The savings scale with context length times the number of idle resumes. The cost is lossy context, the same tradeoff as KV-cache eviction or summarization-based memory.
- **Nested sessions = orchestrator/worker with context isolation.** Subtasks run in separate contexts and return only results. That keeps the parent context short (cheaper prefill, less attention dilution) and is the agent-level analogue of keeping the hot KV working set small. Removing the model selector suggests Anthropic is routing per subtask internally, which is a routing product decision worth watching.
- **PS5 numbers are a memory-bandwidth lesson.** GPU (~448 GB/s GDDR6, unified) vs CPU path: decode is bandwidth-bound, so a ~1000x gap mostly reflects the CPU path's poor effective bandwidth and missing kernels, not raw FLOPs. A 27B model at ~20 tok/s implies aggressive quantization (~4-bit) to fit and stream.
- **16 GW of TPU** at ~1 to 1.5 kW per accelerator all-in is on the order of 10M chips. If even partially real, Anthropic's serving cost per token falls on custom silicon, which is what supports the "adjusted profitable" claim and the generous Max plan economics.

## Real-World Application / Actionable Step
- **Steal idle compaction for your own agent harness and router:** track time since last call per session. If it approaches the provider cache TTL and the context is large, either send a cheap keep-warm or compact while warm. Log cached vs uncached prefill to quantify the savings (see [[2026-10-06-WorldofAI-GPT-Next-Leak-Fable-5-5-Gemini-4-Argon-RSI]]).
- **Use nested sessions for experiment sweeps:** one parent session per research question, children per ablation (quant bits, pruning ratio), and only metrics returned to the parent. This keeps the parent context small and cheap.
- **Wire OTel from the Agent SDK into your existing tracing backend** so router decisions (model chosen, tokens, cache hits, latency) sit next to agent spans.
- **Security hygiene:** the OpenAI case is a reminder that physical and insider threats outrank exotic attacks. Keep checkpoints of unreleased compressed models in access-logged storage.
- **Finance:** do not size an Anthropic IPO position off YouTube revenue figures. Wait for the public S-1, and reconcile run rate vs quarterly vs adjusted vs GAAP (2025 GAAP net loss was ~$42B).
