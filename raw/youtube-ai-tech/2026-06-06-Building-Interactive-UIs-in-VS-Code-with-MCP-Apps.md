# Building Interactive UIs in VS Code with MCP Apps

**Channel:** AI Engineer  
**Published:** 2026-06-06  
**Source:** https://www.youtube.com/watch?v=_xIwFcnHqp4  

## TL;DR
Marlene Mhangami and Liam Hampton from Microsoft/GitHub demonstrate how the Model Context Protocol (MCP) has evolved to support "MCP Apps," allowing LLMs to render rich, interactive UI components directly within chat interfaces like VS Code and GitHub Copilot. This shift moves beyond static text/ASCII art to functional tools like interactive flame graphs, analytics dashboards, and design canvases, all running in sandboxed iframes to maintain host security.

## Key Takeaways
- **MCP Apps Evolution:** Servers can now return UI resource references (HTML/JS/CSS) that the host renders in a sandboxed iframe, enabling live interaction between the user, the app, and the server.
- **Security Architecture:** The "hamster in a cage" model uses iframes to ensure MCP apps cannot access VS Code settings, local file systems (unless permitted), or external APIs without explicit routing through the server.
- **Developer Workflow:** Demonstrated a Go application profiler where a flame graph is rendered in the chat, allowing the developer to explore performance bottlenecks without leaving the IDE or switching contexts.
- **Ecosystem Integration:** VS Code now features an MCP server gallery (search `@mcp` in extensions); major players like Shopify, Figma, and Excalidraw are already shipping MCP-compatible apps.

## Architecture & Optimization Mechanics
- **Resource Routing:** The host (VS Code) fetches HTML from a UI reference generated by the server. This reduces token consumption as the model no longer needs to narrate data structures—it simply invokes a tool that returns a visual component.
- **Sandboxing:** UI components are isolated from the host environment, preventing malicious servers from compromising the user's workspace while still allowing back-and-forth data freshing between the app and the server.
- **Language Support:** Examples showed Go profiling (pprof) data being transformed via a TypeScript MCP server into a React-based interactive flame graph.

## Grounded Context (Web Enrichment)
Anthropic officially released the **MCP Apps extension** in January 2026, marking a significant leap in the protocol's utility. While initially focused on data sharing, MCP is now a platform for "micro-frontends" inside AI clients. Integration with **VS Code Insiders** and **GitHub Copilot's Agent Mode** has made this the standard for building agentic tools.

Recent developments show that the **OpenAI Apps SDK** has moved toward MCP compatibility, suggesting a convergence of standards for how AI models interact with rich interfaces. Partners like **Canva** and **Asana** are using this to let users perform complex multi-step actions (like drafting a project plan or editing a design) directly within the chat sidebar.
