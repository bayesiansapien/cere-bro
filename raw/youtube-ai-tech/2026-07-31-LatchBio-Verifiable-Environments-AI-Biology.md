# Verifiable Environments for AI in Biology (Kenny Workman, LatchBio)

**Channel:** AI Engineer
**Published:** 2026-07-31
**Source:** https://www.youtube.com/watch?v=3ZMUiFaQ3qg

## TL;DR
Workman's central bet: data analysis code is to biology what code was to software engineering, an executable substrate that makes otherwise unverifiable scientific work gradeable and therefore RL-trainable. LatchBio pivoted from a biotech data-tooling vendor into a benchmark-and-agent lab, shipping SpatialBench (146 verifiable problems from real spatial biology workflows), a human-verified subset, and SpatialBench-Long for multi-day scientific reasoning. Frontier models score 20-38%. The talk is unusually honest about what broke: their initial ground truths were bad in ways only human cross-grading revealed, rubric scores correlate only loosely with verifiable outcomes, and their new biosecurity evaluation found models refuse innocuous routine tasks far more often than they refuse disguised red-team requests.

## Key Takeaways
- **Biology's data curve is log-linear and enormous.** Driven by three experiment classes: single cell (2-6 TB per run), spatial biology (up to 7 TB per run), and proteomics (a few hundred GB). A single experiment can exceed what fits on a laptop. Growth rate is second only to particle colliders.
- **The verifiability thesis.** Modern biology follows a fixed loop: choose a biological model, generate data, process it, interpret against prior literature, make a claim. Because the processing step is code, it is executable and checkable, which gives you the substrate for benchmarking and RL that raw scientific reasoning lacks.
- **Tools in this domain take days or weeks.** This is not a metaphor. It breaks every assumption baked into agent harnesses designed around second-scale tool calls.
- **The missing capability is between knowing biology and writing code.** Frontier models can do both and still cannot extract scientific insight from real data, because that requires data analysis plus domain reasoning simultaneously.
- **Four properties of a good biological eval.** Verifiable (success checkable by a function). Durable (a valid alternative analysis path must not be marked wrong, so ground truth has to be invariant across paths). Requires interaction with the data rather than memorized knowledge. Non-single-turn.
- **Human verification demolished their assumptions.** A task asking to split a gene list by activity, score cells, find neighbors "within an appropriate radius," and compute Spearman correlation contains at least five unspecified choices. These bad tasks were invisible until scientists graded each other's work. Their conclusion: in the absence of canonical ground truth, expert cross-grading is the best available proxy.
- **Building evals forces more rigor than doing the work.** Workman notes that many bioinformatics QC thresholds are arbitrary numbers nobody examines, and teaching a machine to do the analysis surfaces which structures are actually load-bearing.
- **Long-horizon tasks cost a week of three people each.** Example: given a primary tumor biopsy plus metastatic biopsies, reconstruct which region of the tumor seeded the metastasis using both genetics and mRNA. No model gets this right yet.
- **Rubrics are the current unsolved piece.** For long horizons, terminal verifiable reward is too sparse. They build rubrics from "choke points," nodes in the analysis tree invariant across valid paths. These correlate with verifiable outcomes but only loosely, which they say is not yet good enough for RL or benchmarking.
- **The biosecurity finding is the alarming one.** They built routine scientist-style tasks alongside red-team tasks engineered to look innocuous (clone a gene into bacteria described as GFP, actually a toxin or viral bootstrap component). Models refuse the routine tasks drastically more often than the red-team tasks. Refusal is anti-correlated with actual risk.
- **The flywheel.** Work with kit manufacturers to learn what matters, build benchmarks from that, get frontier labs to compete on them, which makes the models better at LatchBio's own products. Labs adopted the benchmarks without telling them.

## Novel Revelations and AI Optimization Intersections
The rubric problem is the transferable one and it is structurally identical to a problem in evaluation-driven optimization. Workman's "choke points" are nodes in a solution DAG that are invariant across valid paths, which is exactly the property you want from a process reward model: a signal available before termination that does not penalize legitimate methodological diversity. His honest finding, that these choke-point rubrics correlate only loosely with terminal outcomes, is a direct warning about process reward models generally. If an intermediate signal is only loosely coupled to the outcome you care about, optimizing against it will drift.

The durability requirement is the deeper insight and it has an underappreciated analogue in compression evaluation. LatchBio's failure mode was ground truth that implicitly encoded one analysis path, so a model taking a different valid route was scored wrong. The compression analogue: evaluating a pruned or quantized model against reference outputs from the dense model penalizes valid-but-different generations, conflating "changed" with "degraded." Every distillation pipeline that scores students by similarity to teacher outputs has this bug. The fix is the same one LatchBio arrived at, construct the check against a path-invariant property of the answer rather than against a specific answer.

The days-to-weeks tool latency also forces an architecture nobody in the standard agent stack builds for: the agent must be checkpointable and resumable across a tool call that outlives the process. This is the same constraint General Reasoning hit with weeks-long inference blowing past their 8-step off-policy tolerance, arrived at independently from a completely different domain.

## Grounded Context (Web Enrichment)
The benchmarks are real and published. SpatialBench (arXiv 2512.21907) is 146 verifiable problems across five spatial technologies and seven task categories, each providing a data snapshot immediately prior to an analysis step plus a deterministic grader checking recovery of a key biological result. The reported numbers fill in what the talk left vague: base model accuracy sits at 20-38% across Claude Opus 4.7, GPT-5.5, Gemini 3.1 Pro, and Grok-4.20, with strong model-task and model-platform interactions. SpatialBench-Long (arXiv 2605.28065) is the long-horizon extension where agents must recover biological claims from raw data and experimental context with no prescribed method. The human-verification work is documented separately on their blog, and LatchBio has since published scBench for single-cell RNA-seq (arXiv 2602.09063) and aggregates everything at benchmarks.bio.

One finding in the SpatialBench paper that Workman did not mention in the talk but which is arguably its most important result: harness design has a large empirical effect on performance, and the paper explicitly argues tools, prompts, control flow, and execution environment should be treated as first-class objects to evaluate and improve. That is the same conclusion Polar's harness-variance numbers force from the RL side. Two independent lines of 2026 evidence now say the scaffold is a comparable-magnitude variable to the model.

The Claude Science launch he references is confirmed: Anthropic shipped it June 30, 2026, as a workbench with 60+ scientific databases spanning genomics, single-cell, proteomics, structural biology, and cheminformatics, using a coordinating agent that dispatches to specialist sub-agents with a separate reviewer agent checking citations and calculations. It builds on Claude for Life Sciences (October 2025, with Novo Nordisk, Sanofi, AbbVie, AstraZeneca, and Genmab as anchor customers, and a 10x Genomics connector for exactly the single-cell and spatial data LatchBio benchmarks). LatchBio benchmarks appearing in Anthropic model cards is consistent with the public record.

## Real-World Application / Actionable Step
1. **Audit distillation and compression evals for path-dependence.** Any eval that scores a compressed model by similarity to dense-model outputs inherits LatchBio's durability bug. This week, take one existing eval and rewrite the check to test a path-invariant property of the output instead of matching the reference generation. If the pruned model's score moves substantially, the previous number was measuring divergence, not degradation.
2. **Treat the loose rubric-to-outcome correlation as a warning about process rewards.** If any routing or compression work uses intermediate signals as proxies for final quality (layer-wise reconstruction error, per-step confidence, judge scores on partial outputs), measure the correlation to terminal quality explicitly before optimizing against it. Workman's team found the correlation too weak to trust and said so, which is the honest version most teams skip.
3. **The refusal-anti-correlation finding is directly relevant to routing.** If models refuse benign domain-specific requests more than disguised harmful ones, then refusal rate is a per-model, per-domain property that a router must account for. A cheap model that refuses 15% of legitimate technical queries has a hidden cost that accuracy benchmarks do not capture. Add refusal rate on legitimate in-domain queries to router evaluation as a distinct metric.
4. **Steal the flywheel structure.** Build the benchmark for the thing you actually need models to be good at, publish it, and let labs optimize against it. LatchBio got frontier labs to improve models for their product without paying for post-training. If there is a routing or efficiency capability no public benchmark measures, publishing a good one is cheaper than training for it.
5. **Design for tool calls that outlive the process.** If biology tools take days, the harness needs durable checkpoint and resume. Any internal agent that touches long-running jobs (training runs, large evals, batch inference sweeps) has the same requirement, and most harnesses assume the process stays alive.
