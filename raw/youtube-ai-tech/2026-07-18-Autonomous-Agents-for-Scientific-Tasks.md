# Autonomous Agents for Scientific Tasks

**Channel:** AI Engineer
**Published:** 2026-07-18
**Source:** https://www.youtube.com/watch?v=XLEYtv3cMlw

## TL;DR
Sina Shahandeh (Radicait) argues that coding agents already handle the implementation half of the scientific method well but saturate on the hard half: generating novel, radical hypotheses ("research taste"). His fix is a structural prompting trick. Explicitly decompose a research problem into a linked hierarchy of components (data, architecture, loss, metrics, scripts), then force the agent to reason over each node of that hierarchy when proposing changes. This turns a shallow hyperparameter search into a comprehensive, scaffold-guided search that surfaces radical moves (for example, jumping from 2.5D to 3D convolutions) an ordinary optimization loop would never attempt. He frames the hierarchy as "chain-of-thought for research," a scaffold that scales test-time compute across a problem's structure.

## Key Takeaways
- The bottleneck in auto-research is not implementation or memory, it is hypothesis generation. Agents plateau because they keep tweaking known knobs instead of restructuring the problem. Top human researchers keep climbing because they keep generating good hypotheses.
- The core trick: use the agent itself to generate a hierarchical, hyperlinked document tree of the problem (README at level 1, sub-components at levels 2 and 3, actual code at the leaves). This scaffold is cheap to induce with one prompt and mirrors how a human decomposes a long-horizon research problem.
- With the scaffold in place, the agent can generate 100+ candidate solutions by systematically modifying every component, not just hyperparameters. This is what unlocked the radical 2.5D-to-3D convolution change in Radicait's CT-to-PET model.
- Hypotheses and implementations should be reviewed adversarially or collaboratively by a second, stronger-reasoning model. Shahandeh routes hypothesis generation and critique to higher test-time-compute models (he references "GPT-5.5 Pro" via Peter Steinberger's Oracle CLI, which packages code plus data and ships it to the API).
- Multimodal observation is the hard unsolved gap. No current LLM reliably identifies tiny scientifically meaningful features (a cancerous lung nodule) because they are not trained on scientific imaging. Until models can "observe" like a trained scientist, you cannot fully close the loop inside a data center.
- Custom skills close specific sub-loops: he built a Gemini-based image-review skill that acts as a qualitative QC step inside the image-registration optimization (checking mask alignment, cropping, truncation) where quantitative metrics alone fail.

## Architecture & Optimization Mechanics
This talk is directly on Amit's turf because the running example is an ML optimization loop, and the meta-technique is a test-time-compute scaling strategy. Shahandeh's key insight is that the hierarchy is a way to allocate reasoning tokens across the structural degrees of freedom of a model, rather than spending them all on local hyperparameter hill-climbing. That reframing matters for anyone doing architecture search or MoE/attention design: the plateau is a search-space problem, and an explicit component decomposition changes which regions of the space the agent will even consider.

The routing pattern is worth stealing wholesale. He splits the loop into cheap and expensive roles: a fast coding agent does implementation and bookkeeping, a strong multimodal model does qualitative observation/QC, and a high-compute reasoning model does hypothesis generation and critique. This is exactly the cost-aware model-routing pattern Amit works on, applied to an autonomous research pipeline. The economically interesting claim is implicit: you only pay for the most expensive model at the two points where taste and observation actually matter (hypothesis and critique), keeping the bulk of the loop cheap. His honest caveat is that these scaffolding tricks are a stopgap. As models get better at compartmentalizing problems in post-training, the hand-built hierarchy should fade, the same way explicit chain-of-thought scaffolding gave way to models that reason natively.

## Grounded Context (Web Enrichment)
The talk lands squarely in a fast-moving 2025 to 2026 research wave. The framing of "AI for Science" maturing into "Agentic Science" is now a named survey topic (arXiv:2508.14111), and there is an AAAI 2026 tutorial dedicated to agentic AI for scientific discovery. Shahandeh's specific medical-imaging application is being validated in the clinic: the Journal of Nuclear Medicine published a June 2026 pilot of an LLM-orchestrated agent doing end-to-end PET/CT interpretation, with the LLM selecting DICOM series, coordinating registration and SUV conversion, and invoking segmentation, which is essentially the tool-orchestration loop he describes. His hypothesis-generation thesis is corroborated by systems like DeepMind's AlphaEvolve, which couples LLMs to an evolutionary search loop to propose, test, and refine code-based hypotheses, and by 2025 work on iterative hypothesis generation using Monte Carlo Nash-equilibrium self-refining trees. Where he is most credible is the multimodal-observation gap: reviews of synthetic medical image generation confirm that CT-to-PET and CT-to-MRI translation now lean on adversarial and diffusion models, but reliable detection of small pathological features remains a hard, data-starved problem, exactly the limitation he flags.

## Real-World Application / Actionable Step
Adopt the hierarchy-decomposition scaffold for your own model-optimization runs. Before the next pruning or routing experiment, have a coding agent generate a linked component tree of the problem (data, architecture, quantization scheme, kernel, eval harness) and then require the agent to propose one radical change per component rather than a hyperparameter sweep. The concrete payoff is escaping the plateau where an agent only ever tries "lower the learning rate" instead of "restructure the attention block." Second, implement Shahandeh's role-routing explicitly in your harness: cheap model for edits and logging, high-compute model gated to hypothesis and critique steps only. This is a low-effort way to test whether spending reasoning tokens on structure rather than local search improves your compression or routing results without inflating total cost.
