# It's time to fly | OpenAI Codex Enterprise Expansion

**Channel:** OpenAI  
**Published:** 2026-06-03  
**Source:** https://www.youtube.com/watch?v=bJcA23ckzcY  

## TL;DR
OpenAI has announced a strategic evolution of **Codex**, moving it beyond developer-centric code assistance into a comprehensive **enterprise work platform**. The update introduces the **GPT-Rosalind** frontier model and three major features: **Sites** (hosted web app creation), **Annotations** (in-place natural language editing), and role-specific plugins that bundle 110 automated "skills" for non-technical roles. This expansion is supported by a new multi-cloud partnership making Codex available on **AWS Bedrock**.

## Key Takeaways
- **Codex Sites:** Users can now generate, host, and share interactive web applications and dashboards directly via a URL, enabling non-technical teams to build internal tools autonomously.
- **In-Place Annotations:** A new refinement interface allows users to highlight specific outputs and provide natural language instructions to modify them without re-prompting the entire task.
- **Enterprise Ecosystem:** Launched with 62 business application connectors (e.g., Snowflake, Salesforce, Slack) and role-tailored automation "skills."
- **Multi-Cloud Strategy:** Codex and GPT-Rosalind are now generally available on AWS via Amazon Bedrock, simplifying procurement and security for large-scale enterprise deployments.
- **GPT-Rosalind Model:** The new underlying engine optimized for long-horizon enterprise tasks, agentic reasoning, and high-fidelity UI generation.

## Core Architecture & Research Claims
- **Agentic Skill Bundles:** Instead of generic tool-use, Codex now employs "skill bundles" which are pre-optimized multi-step workflows for specific professional domains (Data Analysis, Marketing, Ops).
- **Persistent Interaction Environments:** Sites are not just static outputs but persistent, stateful environments where humans and agents can continue to collaborate over time.
- **Demographic Shift:** OpenAI reports that 20% of the 5 million weekly active Codex users are now non-developers, a segment growing three times faster than traditional software engineering users.

## Grounded Context (Web Enrichment)
The June 2026 "It’s Time to Fly" announcement represents OpenAI’s direct counter-offensive to Anthropic’s **Claude Code** and the rapid adoption of **MCP Apps**. By introducing **Sites** and **Annotations**, OpenAI is attempting to close the "feedback loop" that previously required users to copy-paste code into separate IDEs or hosting platforms. 

The availability of **GPT-Rosalind** on **AWS Bedrock** is a significant milestone, as it breaks the exclusive bond between OpenAI and Microsoft Azure for frontier model hosting. This multi-cloud approach, combined with the 110+ automated skills, signals that OpenAI is no longer just selling "intelligence" as an API, but is now providing a full-stack "work runtime" for the autonomous enterprise.
