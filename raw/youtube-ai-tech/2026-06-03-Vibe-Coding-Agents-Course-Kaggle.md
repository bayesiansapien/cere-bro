# Sneak peek: Vibe coding AI agents course with Kaggle

**Channel:** Google Cloud Tech  
**Published:** 2026-06-03  
**Source:** https://www.youtube.com/watch?v=eG5RpppF-Xo  

## TL;DR
Google Cloud and Kaggle have announced an intensive 5-day course, **"Coding AI Agents,"** starting June 15, 2026. The course focuses on **"Vibe Coding"**— a new development paradigm where humans provide high-level intent and design while autonomous agents handle implementation and deployment. The curriculum introduces the **Anti-Gravity 2.0** platform for multi-agent orchestration and the **ADK 2.0** (Agent Development Kit), which uses a graph-based engine to bridge the gap between dynamic reasoning and deterministic production workflows.

## Key Takeaways
- **The "Vibe Coding" Shift:** Development is moving from manual syntax writing to "supervisory engineering," where agents are orchestrated to build complex systems (e.g., Google’s demo of a custom OS built in 12 hours by 93 sub-agents).
- **Anti-Gravity 2.0:** A standalone desktop and CLI ecosystem that serves as a central hub for agent interaction, allowing for parallel task execution and scheduled background automation.
- **ADK 2.0 (Agent Development Kit):** An open-source, engineering-first SDK that supports graph-based workflows, enabling deterministic routing and complex "fan-out/fan-in" agent patterns.
- **Managed Agents API:** Provides isolated, persistent Linux environments where agents can resume tasks across multiple calls, maintaining state (files and memory) for long-running missions.
- **Kaggle Game Arena:** A real-time, ELO-based evaluation platform where agents (e.g., Gemini 3.5 Flash vs. GPT 5.5) compete in strategic games like Chess and coding challenges to measure reasoning performance.

## Core Architecture & Research Claims
- **Agent2Agent (A2A) Protocol:** A new interoperability standard allowing Google-built agents to coordinate seamlessly with agents from other vendors/platforms.
- **Graph-Based Execution Engine:** ADK 2.0 replaces hierarchical structures with graphs to handle the non-linear nature of autonomous task solving.
- **Gemini 3.5 Flash:** A model co-optimized for the Anti-Gravity harness, offering 1M+ context and ultra-low latency required for the high-frequency loops of agentic development.
- **MCTP (Model Context Protocol) Integration:** 50+ Google Cloud services (BigQuery, Maps, etc.) are now MCTP-enabled by default, providing standardized "real-world" bridges for autonomous agents.

## Grounded Context (Web Enrichment)
The "5 Days of Vibe Coding" course marks the formalization of the **Agentic Era** at Google Cloud. The centerpiece of this launch, **Anti-Gravity 2.0**, represents a strategic pivot toward making agents "universally accessible" for enterprise developers. By leveraging **Gemini 3.5 Flash**, which is reported to be up to **12x faster** than other frontier models when running inside the Anti-Gravity harness, Google is positioning itself as the high-performance runtime for autonomous software engineering.

The introduction of **Kaggle Game Arena** addresses the growing "static benchmark" problem in AI evaluation. By using an ELO rating system, researchers can now measure agent performance in dynamic, competitive environments, which is a more accurate proxy for real-world software development than traditional multiple-choice tests. Furthermore, the **Managed Agents API** with isolated Linux sandboxes provides the "security-first" architecture required for enterprises to trust agents with production-level read/write access to their infrastructure.
