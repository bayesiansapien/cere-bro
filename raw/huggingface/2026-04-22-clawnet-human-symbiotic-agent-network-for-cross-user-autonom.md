# ClawNet: Human-Symbiotic Agent Network for Cross-User Autonomous Cooperation

AI agent technology is advancing rapidly from conversational generation to autonomous execution. Early conversational systems were limited to text generation and could not interact with external environments. Tool-augmented agents then introduced API-level interaction through function calling and tool-use mechanisms. More recently, OS-level agents have achieved direct control over files, terminals, and desktop applications. Yet whether single-agent or multi-agent, these systems invariably serve a single user. We propose a human-symbiotic agent paradigm where each user owns an agent system permanently bound to its owner, comprising multiple identity agents each corresponding to a specific collaborative context. We instantiate this paradigm in ClawNet, an open-source identity-governed agent collaboration framework with a cloud-edge architecture. ClawNet enables cross-user collaboration through identity binding, scoped authorization, and action-level accountability, providing governance primitives that are absent in current agent frameworks.
