# RadAgent: A tool-using AI agent for stepwise interpretation of chest computed tomography

RadAgent is a tool-using AI agent for stepwise interpretation of chest computed tomography (CT) scans. The agent decomposes complex radiology interpretation tasks into sequential tool-augmented reasoning steps, integrating specialized medical image analysis tools with large language model reasoning. The system demonstrates structured, stepwise workflows for chest CT interpretation, enabling more transparent and verifiable diagnostic reasoning compared to end-to-end approaches. Experiments demonstrate improvements in structured CT report generation and finding localization on benchmark datasets.
