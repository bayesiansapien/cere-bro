# Generative Quantum-inspired Kolmogorov-Arnold Eigensolver

This paper presents the generative quantum-inspired Kolmogorov-Arnold eigensolver (GQKAE), a parameter-efficient extension of the generative quantum eigensolver (GQE) for quantum chemistry problems. GQKAE replaces dense nonlinear feed-forward network (FFN) components with hybrid quantum-inspired Kolmogorov-Arnold network (HQKAN) modules. Across benchmarks on H4, N2, LiH, C2H6, H2O, and the H2O dimer, GQKAE achieves chemical accuracy comparable to the GPT-based architecture employed in GQE, while reducing trainable parameters and memory by approximately 66% and achieving notable wall-time speedup.
