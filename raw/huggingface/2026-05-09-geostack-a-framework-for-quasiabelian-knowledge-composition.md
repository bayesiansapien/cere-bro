# GeoStack: A Framework for Quasi-Abelian Knowledge Composition in VLMs

GeoStack introduces a framework for quasi-Abelian knowledge composition in vision-language models (VLMs), addressing how visual and language knowledge components can be composed in a principled algebraic manner. The framework uses geometric constraints for multi-domain composition, establishing a theoretical foundation for how knowledge can be stacked and combined in VLMs without catastrophic interference.
