# Instruction-Guided Poetry Generation in Arabic and Its Dialects

The authors introduce a large-scale instruction-based dataset for poetry generation in Modern Standard Arabic and various Arabic dialects. Their work enables tasks like writing, revising, and continuing poems based on specific criteria such as style and rhyme, alongside poetry analysis capabilities. When fine-tuning language models on this dataset, the resulting systems can effectively generate poetry that is aligned with user requirements, based on both automated metrics and human evaluation with native Arabic speakers. The team has made their data and code publicly available through their GitHub repository.
