# ComboStoc: Combinatorial Stochasticity for Diffusion Generative Models

In this paper, we study an under-explored but important factor of diffusion generative models, i.e., the combinatorial complexity. The authors demonstrate that high-dimensional data with associated structured attributes may not be sufficiently represented in existing training schemes.

They propose ComboStoc, a method that constructs stochastic processes leveraging combinatorial structures. This approach accelerates network training across multiple data types, including images and 3D shapes. Additionally, the method enables novel test-time generation using asynchronous timesteps for different dimensions and attributes, providing enhanced control during the generation process. Code is publicly available on GitHub.
