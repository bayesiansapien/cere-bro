- **Dynamic Workflows (research preview) in Claude Code** ([@ClaudeDevs](https://nitter.net/ClaudeDevs/status/2060044853279617150#m), [Claude Code docs](http://code.claude.com/docs/en/workflows), [Anthropic blog](https://claude.com/blog/introducing-dynamic-workflows-in-claude-code)). Claude generates a JavaScript orchestration script on the fly, fans work across parallel subagents, and uses adversarial verification before reporting back. Up to 1000 agents per run, 16 concurrent. Activate by including "workflow" in a prompt, or set /effort ultracode for automatic triggering. Available on Max, Team, Enterprise, and the API (Bedrock, Vertex AI, Foundry); on by default for Max and Team plans, enterprise admins can opt in via managed settings. Workflows are reusable, savable as slash commands at project or user scope, and runnable in the background while you continue working. Ken Huang's RSS post today gives a detailed teardown of the orchestration model vs subagents vs agent teams; see the daily digest's Industry Pulse for the cross-link.
