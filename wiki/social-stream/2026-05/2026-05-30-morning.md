- **Claude Opus 4.8 mid-conversation system messages + auto-caching cluster** ([@ClaudeDevs thread](https://nitter.net/ClaudeDevs/status/2060432691288576207#m), [docs](https://platform.claude.com/docs/en/build-with-claude/mid-conversation-system-messages), [auto-caching docs](https://platform.claude.com/docs/en/build-with-claude/prompt-caching#automatic-caching)). A four-tweet sequence laying out a small but operationally important Opus 4.8 capability. Previously, editing the top-level system prompt field invalidated the prompt cache for everything that followed, which made dynamic instruction injection expensive. In Opus 4.8 you can now pass a system-role *message* mid-conversation, which Claude treats as an authoritative instruction from that point onward, and pair it with automatic caching so updates remain inside the cache. Lance Martin is cited as the practitioner explainer (his X article body was not fetched due to expired cookies). The cumulative direction is clear: input tokens are now the dominant cost driver (per Cursor's 05-29 Developer Habits report, surfaced in yesterday's slots), so Anthropic is hardening the cache-preservation primitives that the long-horizon agent workload depends on. Pair with today's [digest deep dive](../../daily-digest/2026-05/2026-05-30.md) on the Salesforce 231-day-migration case study, which is the enterprise-scale workload these primitives are aimed at.

- **Cursor auto-review mode and classifier subagent** ([@cursor_ai thread](https://nitter.net/cursor_ai/status/2060406013098897765#m), [changelog](http://cursor.com/changelog/auto-review)). Cursor 3.6 ships auto-review, a new run mode that reduces approval prompts while keeping safety boundaries. Allowlisted tool calls run immediately, sandboxable calls run in the sandbox, and *everything else* is routed to a separate classifier subagent that decides one of three outcomes: allow the call, try a different approach, or ask the user for approval. The classifier can be steered with custom instructions. This is a concrete instance of the routing-as-policy pattern the wiki has been tracking, applied to the safety layer of an agentic IDE: a small, fast model gates a larger one. It is the same architectural bet as AgentDoG 1.5 (today's safety paper in the digest, where a 0.8B–8B classifier guards a frontier agent at one-percent of Docker-level overhead) — wrap the model, do not harden it.
