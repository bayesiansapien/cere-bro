- **Kilo Product Week: five agentic-coding features in one day (cluster of 6)** ([@kilocode](https://nitter.net/kilocode/status/2066143820840882381), [blog.kilo.ai](https://blog.kilo.ai/p/coding-plans-are-live-in-kilo)). Kilo shipped: (1) **Coding Plans**, buy a MiniMax M3 plan ($20/mo, ~1.7B tokens, 1M context) with your existing Kilo balance, no BYOK juggling; (2) **REVIEWS.md**, a repo-root file that teaches the review agent your conventions per-repo, the review-standard analogue of AGENT.md, the same "compile standards into agent gates" pattern as the 06-13 Cursor Auto-review and TRACE work; (3) **Kilo Console**, a browser UI to manage worktrees/sessions/settings without hand-editing JSON; (4) **Agent Manager**, run multiple agents in parallel, each in an isolated git worktree, to avoid the file-clobbering chaos of six agents in six tabs; (5) **KiloClaw**, a hosted OpenClaw with a morning-brief skill that pulls calendar conflicts unprompted. The connecting thread, and why it sits next to today's HarnessX and HarnessBridge papers in the digest, is that the harness (review rules, worktree isolation, skills, token plans) is being productized as the place value accrues. Their own framing: most engineers run 2-5 coding tools at once and every one is a moving pricing target (Roo Code shut down, Copilot went usage-based), so own the layer above them.
