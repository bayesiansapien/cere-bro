## Posts

- **Anthropic files S-1 for an IPO, plus a giant SpaceX compute deal** ([@ns123abc](https://nitter.net/ns123abc/status/2061496934460731672#m), [Anthropic announcement](https://www.anthropic.com/news/confidential-draft-s1-sec)). Anthropic confidentially submitted a draft S-1 registration to the SEC, giving it the option to pursue an IPO once review completes (no share count or price set yet). In a separate tweet @ns123abc reported a SpaceX compute deal said to include ~325,000 NVIDIA GPUs across the Colossus and Colossus II clusters, plus hyperscale CPUs, exabyte storage, and high-speed interconnects, at roughly $1.25B per month through May 2029. The framing ("OpenAI just lost the race to go public") is the curator's spin, but the S-1 itself is the consequential fact. See the [daily digest](../../daily-digest/2026-06/2026-06-02.md) Industry Pulse.

- **NVIDIA Vera Rubin enters full production** ([@nvidia](https://nitter.net/nvidia/status/2061502320752419085#m), [NVIDIA newsroom](https://nvda.ws/3RQ4FrR)). The Vera Rubin platform is now a multi-rack pod-scale system in full production, unifying five connected rack-scale systems (Vera Rubin NVL72, Vera CPU rack, Rubin LPX, BlueField-4, Spectrum-6 Ethernet) and claiming 10x agent throughput at scale versus the previous Grace Blackwell generation. Microsoft, Dell, and CoreWeave are named as standing up early systems. This is the datacenter half of the "agent is the unit of compute" story the wiki tracked from the 06-01 GTC keynote.

- **NVIDIA sovereign-AI map and Nemotron** ([@nvidia](https://nitter.net/nvidia/status/2061606345007104093#m), [NVIDIA blog](https://nvda.ws/4vgAOav)). The attached image is a night-lights render of Eurasia with datacenter-stack icons pinned to roughly a dozen national flags (France, Germany, Poland, Israel, Saudi Arabia, UAE, India, Vietnam, Malaysia, Singapore, South Korea, Japan, Taiwan), illustrating the pitch that regional leaders are building in-country datasets, sovereign models, and agentic apps on NVIDIA Nemotron tailored to local languages and economies. The visual is marketing, but it signals where NVIDIA expects sovereign-AI demand to concentrate.

- **Nemotron 3 Ultra tops open-weights PinchBench** ([@kilocode](https://nitter.net/kilocode/status/2061537598175141987#m), [PinchBench](http://pinchbench.com/?weights=open)). Kilo Code reports NVIDIA's Nemotron 3 Ultra (550B) is the top open-weights model on PinchBench v2 at 89.9% average across 147 real OpenClaw agent tasks, free to run, and that NVIDIA used PinchBench on a Jensen Huang keynote slide to position Nemotron against frontier labs (Nemotron tied for the lead on Agent Productivity at 91%). For context, the same leaderboard's overall top is Claude Opus 4.8 Fast at 93.5%, so open weights are closing but not closing the gap.

- **OpenAI models generally available on Amazon Bedrock** ([@mattsgarman](https://nitter.net/mattsgarman/status/2061591884892344556#m), [AWS blog](https://aws.amazon.com/blogs/machine-learning/openai-models-and-codex-on-amazon-bedrock-are-now-generally-available/)). AWS's Matt Garman announced GPT-5.5, GPT-5.4, and Codex are now GA on Amazon Bedrock at first-party OpenAI pricing, running on Bedrock's inference engine and counting toward existing AWS commitments. This puts OpenAI's frontier models and coding agent directly inside the cloud where many enterprises already keep their data, one month after the expanded OpenAI-AWS partnership.

- **Cursor reworks Teams pricing** ([@cursor_ai](https://nitter.net/cursor_ai/status/2061550723503194426#m), [Cursor blog](https://cursor.com/blog/teams-pricing-june-2026)). Cursor is raising Teams usage limits and splitting each seat's included usage into two pools: a generous Composer-and-Auto pool reserved for first-party models, plus a separate third-party API pool. It also adds a Premium seat aimed at the heaviest agent users (5x usage at 3x cost), citing Composer 2.5 delivering frontier-level performance at a fraction of frontier price. Changes start immediately for new customers, July 1 for renewals.

- **Claude Opus 4.8 parallel-tool bug fixed, rate limits reset** ([@ClaudeDevs](https://nitter.net/ClaudeDevs/status/2061501787769893055#m)). Anthropic's developer account said an issue caused Opus 4.8 requests to trigger more parallel tool calls than intended (unrelated to dynamic workflows), which made some Claude Code sessions spawn excessive parallel subagents and burn usage faster than expected. They fixed it and reset 5-hour and weekly rate limits for all Pro and Max users. A small but concrete operational detail for anyone running Claude Code agents heavily.

- **Continually learning agents** ([@MillionInt](https://nitter.net/MillionInt/status/2061593846681928179#m)). The lone research-flavored post: the author says their main motivation for working on continually learning agents is the frustration of working with agents that do not, in fact, learn continually. No paper attached, but it names the gap (agents that reset their knowledge every session) that several of today's HuggingFace agent-memory papers, like JAMEL's joint memory-and-exploration training, are trying to close.

Industry/infra signal, adjacent to the sovereign-AI map above.
