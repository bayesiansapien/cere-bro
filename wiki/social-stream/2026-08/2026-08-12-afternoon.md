- **Omarchy Quattro ships, and the interesting part is the token and memory accounting** (cluster of 6) ([@dhh](https://x.com/dhh/status/2087156526058230092) · [Quattro PR](https://github.com/basecamp/omarchy/pull/6231) · [plugin registry](https://omarchyplugins.com/)).
  Three months of work and roughly a thousand pull requests, not yet in general release. Two details carry actual signal. The shell layer is built entirely on Quickshell and runs in **under 300MB of runtime memory once shared library usage is accounted for**, which is a real number for a fully scriptable desktop shell. And the community plugin registry went from **40 plugins to 75 in a single day** before general availability, which is an adoption-velocity datapoint rather than a marketing one. The rest of the cluster is wallpaper polling and a status widget that "gets mad if you don't feed him enough tokens," pouting in red until the rate limit resets. That widget is a small sign of where desktop tooling is heading: token budget as a first-class system indicator, next to battery and network.

- **DHH merges bypassed permission prompts as the default for coding agents** ([@dhh](https://x.com/dhh/status/2087433655891234971) · [PR #6729](https://github.com/basecamp/omarchy/pull/6729)).
  Agents launched from the Omarchy keybinding or menu now start with permission prompts bypassed, whichever agent is the default. His stated reasoning is that harness providers avoid this only because they do not want the liability, and his stated mitigation is that a wrecked Omarchy install can be reinstalled in under a minute. Recovery cost, not restraint, is the safety argument. Worth recording next to the [08-11 harness evolution cluster](../../agentic-systems/2026-08-11-harness-evolution-cluster.md), where three papers on the same day treated the harness as the object being optimized rather than as fixed infrastructure: this is a shipped harness making the most aggressive available choice on the permission axis, and the counter-position arrived the same day from Hugging Face's Elie Bakouch worrying about agents that hold credentials to every tool you use.
