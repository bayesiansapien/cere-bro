## Posts

- **Meta-Harness: optimizing the code around the model beats optimizing the prompt** ([@marfinxx](https://nitter.net/marfinxx/status/2089850130321043799), [post on X](https://x.com/marfinxx/status/2089850130321043799)).

  A saved post summarizing a Stanford and MIT system that automatically evolves the Python harness governing an agent's context, memory, and retrieval. The headline claim is that harness optimization alone produces up to a **6x performance gap on the same benchmark with the model weights frozen**.

  The mechanism is two refusals of how automated agent optimizers normally work. The first is **full diagnostic trace access**. Standard optimizers feed the proposer a compressed scalar reward, sometimes with a short natural-language summary of what went wrong. Meta-Harness instead gives an agentic proposer unrestricted filesystem access to raw execution logs and source code across every past iteration, up to 10 million trace tokens, and lets it inspect them with `grep` and `cat` the way a person debugging a system would. The reason this matters is attribution: a scalar reward can tell you a rollout was bad, but it cannot tell you that the failure at turn 40 was caused by a context decision at turn 6. Recovering that link requires reading the log.

  The second is **causal failure analysis in code space**. Rather than rewording a system prompt, the system isolates confounded regressions, traces a downstream error back to the early context decision that produced it, and rewrites the executable Python function responsible. This is the part that makes the approach qualitatively different from prompt optimization, because a large share of harness failures are program bugs that simply cannot be expressed as a change in instruction wording.

  The reported results, in order of how much they should update you. Discovered context-management policies beat state-of-the-art agentic memory systems by **7.7 points while using 4x fewer context tokens**, and converged 10x faster than traditional optimizers. A single discovered math-retrieval harness raised solve rates on **200 IMO-level olympiad problems by 4.7 points across five completely held-out frontier models**, zero-shot. On production agent pipelines, classification accuracy rose 7.7 points while context token overhead fell 75 percent.

  That transfer result is the one that changes the picture, because it is now the third in twelve days. AI4AI at Test-Time (08-13) had a strong builder model write an inference-time harness for a weaker target, and average target performance across four Theory-of-Mind benchmarks went from 0.49 to 0.91 with the target's weights never touched. AutoDesign (08-14) dropped a learned DesignHarness into seven different code-agent-model configurations and lifted the average score by 12.4 points across all seven. Meta-Harness adds five held-out frontier models on olympiad problems. Three independent results showing a discovered harness transfers to models it was never optimized against is enough to say the thing plainly: **a harness is a portable, reusable artifact with its own value, not a per-model tuning residue.**

  The caveat worth holding is cost. Full filesystem access over 10 million trace tokens per proposal is not cheap, and "10x faster convergence" is measured in optimizer iterations, which is the wrong unit if the token bill per iteration went up by more than 10x. No search-cost accounting is reported. The available details also come from a secondary breakdown rather than the paper itself, so treat the specific figures as reported rather than verified.
