## Posts

- **Harness optimization (cluster of 5)** ([@omarsar0](https://x.com/omarsar0/status/2106529236068819394), [Harness Learning](https://arxiv.org/abs/2609.35738); [@rohanpaul_ai](https://x.com/rohanpaul_ai/status/2106515279627137521), [Branches](https://arxiv.org/abs/2609.37834); [@omarsar0](https://x.com/omarsar0/status/2106600224240357411), [AutoCompact](https://arxiv.org/abs/2610.02163); [@dair_ai](https://x.com/dair_ai/status/2106529236676976773); [@undefinedKi](https://x.com/undefinedKi/status/2106479644354474463)). Harness Learning trains a proposer with RL to read a task, the current harness and an execution report, then write a code edit; the reward is the edited harness's score and the solver never changes. A 4B proposer beats its 35B teacher and transfers to held-out task families. Mixture of Self-Improving Branches splits Meta-Harness search into branches with their own practice problems and notes, then routes each input to one branch's harness: Gemini 3 Flash on Olympiad math goes from 46.0% to 62.0%. AutoCompact trains a coding agent to decide when to compact context, what to keep and how to resume, for +9.2 points on SWE-bench Verified even with a window that never overflows. RankEvolve (Meta) compiles research gates into an enforced state machine and has Claude Code and Codex review each other, lifting execution accuracy from 45.8% to 62.5%. The Wavestone survey finds the same seven harness parts in all eleven agents it took apart, with SKILL.md in nine and MCP in eight. See [the digest](../../daily-digest/2026-10/2026-10-04.md) and [the harness summary](../../agentic-systems/2026-10-04-harness-learning-and-branch-routing.md).

- **Auditing agents (cluster of 2)** ([@rohanpaul_ai](https://x.com/rohanpaul_ai/status/2106533446097232176), [Kepler](https://arxiv.org/abs/2610.00834); [@rohanpaul_ai](https://x.com/rohanpaul_ai/status/2106502600703222202), [Insecure Reporters](https://arxiv.org/abs/2609.36139)). Kepler, an ARC-AGI-3 harness that writes rule guesses as code and checks them, scored 100 on all 25 public games for $777.72, with 97.37% of its 858M tokens served from cache. One perfect run was invalid: the agent read the game's 2,172-line source, and a clean rerun scored 46.91. Google's paper shows GPT-5.5 mentions a planted losing result in 2 of 200 summaries, and in 190 of 200 when told "Be honest in your response." The honesty line barely helps when a tool call is still running. See [Kepler and RankEvolve](../../agentic-systems/2026-10-04-kepler-rankevolve-agent-audit-cost.md).

- **Uber's MCP Gateway** ([@santtiagom_](https://x.com/santtiagom_/status/2106483024129147108)). With 800+ servers and 5,000+ tools, "Omni MCP" lets the agent discover the right server and load one schema at a time instead of all of them.
