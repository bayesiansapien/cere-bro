## Posts

- **Agent compute that compounds (cluster of 4)** ([@SakanaAILabs](https://x.com/SakanaAILabs/status/2109385006603006435), [@hardmaru](https://x.com/hardmaru/status/2109385496237678844), [@rohanpaul_ai](https://x.com/rohanpaul_ai/status/2109447386859033015), [@rohanpaul_ai](https://x.com/rohanpaul_ai/status/2109456891059597313); papers [2610.12176](https://arxiv.org/abs/2610.12176), [2610.04862](https://arxiv.org/abs/2610.04862), [2610.12235](https://arxiv.org/abs/2610.12235)). Sakana's MASS (Multi-Agent Self-Supervision, with UC Berkeley) has one shared 27B open model solve tasks as a team of virtual subagents, search for better team workflows, judge the results itself, and then train on the best team's runs. After two cycles, score per output token reached 1.2-1.6x the base model on four research benchmarks. Training only as the task solver also improved the model as optimizer and evaluator, and multi-agent traces were better training data than single-agent ones. Sakana flags the safety risk: when a model is its own evaluator, shared blind spots can be reinforced as progress. Meta's GitSwarm runs hundreds of agents over one Git repo where each commit cites what it builds on; it scored 79.4% vs 65.1% for one Codex agent on ProgramBench, and 70% of failed research commits were reused later. Amazon's Research World Models use logged experiments to predict whether a change will help before GPU time is spent; past records lifted ranking correlation from 0.506 to 0.774. See [GitSwarm](../../agentic-systems/2026-10-12-gitswarm-compounding-inference.md), [Research World Models](../../agentic-systems/2026-10-12-agent-team-costs-and-research-world-models.md) and MASS in the [10-11 harness summary](../../agentic-systems/2026-10-11-harness-ceiling-and-trained-orchestration.md).

- **Swarms force metered pricing** ([@rohanpaul_ai](https://x.com/rohanpaul_ai/status/2109345465838006445)). In a swarm, a parent agent plans and child agents do narrow, easy-to-check jobs like searching files or running tests, which can be routed to the cheapest model that passes. So agent token volume grows faster than frontier-model revenue, and per-seat pricing, which relied on human typing speed to cap usage, gives way to metering.

- **Inference money (cluster of 3)** ([@rohanpaul_ai](https://x.com/rohanpaul_ai/status/2109479701689565297), [@StockSavvyShay](https://x.com/StockSavvyShay/status/2109400560827068496), [@JayaGup10](https://x.com/JayaGup10/status/2109414688924856810), [@StockSavvyShay](https://x.com/StockSavvyShay/status/2109443155255005364)). The WSJ reports Amazon is in talks to buy Decart for about $7B, after Nvidia talks and a $6B Anthropic deal collapsed. Decart's DOS stack moves workloads across chips and took real-time video from 26 fps on GPUs to about 101 fps on Trainium, so Amazon is buying the software that makes its own chip cheaper per token. Jaya Gupta argues hosted inference is a "permanent reverse auction": easy capital, spare neolab compute and one-line switching keep pushing prices down. IREN reportedly signed a multiyear cloud deal with Anthropic, possibly 50 MW of B300 capacity. See the [Decart summary](../../hardware/2026-10-12-decart-trainium-and-agent-cpu-demand.md) and the [industry summary](../../ai-industry/2026-10-12-inference-reverse-auction-and-capability-funnel.md).

- **The model swallows the harness (cluster of 3)** ([@pmddomingos](https://x.com/pmddomingos/status/2109420932955804040), [@elonmusk](https://x.com/elonmusk/status/2109468545054880123), [@KirkDBorne](https://x.com/KirkDBorne/status/2109404214657245667); paper [2609.35738](https://arxiv.org/abs/2609.35738)). Domingos points at Harness Learning, the CMU paper where a proposer model is trained to rewrite the agent's harness (the program that organizes model calls, tools and information flow) using execution feedback, framed as meta-learning over programs. His read: the learned model is absorbing what used to be hand-written scaffolding. Musk says the same happened with Tesla FSD, where the network ate the C++ code. A 48-page "Understanding Harness Engineering" handbook circulated alongside. Garry Tan pushed the other direction: replace LLM calls with deterministic code wherever possible. See [harness engineering](../../agentic-systems/agent-harness-engineering.md).

- **Karpathy's capability funnel** ([@karpathy](https://x.com/karpathy/status/2109361546505966046), [@IntuitMachine](https://x.com/IntuitMachine/status/2109405466606354943)). Napkin math: about 6B people barely touch LLMs, 1-2B use free chatbots casually, about 20M (0.2%) use frontier models professionally in math and code and see weeks of work done by agents, and about 5,000 inside labs see swarms of thousands of agents running for weeks. He says the gap in shared understanding is widening into a funnel. Critics think 20M is too high.

- **Uber's MCP gateway** ([@stretchcloud](https://x.com/stretchcloud/status/2109352834802258326)). Uber's gateway fronts over 800 MCP servers and 5,000+ tools, mostly generated automatically. A control plane (registry for discovery and ownership) is split from a data plane (a proxy translating MCP calls into HTTP, gRPC and TChannel). A crawler finds new services and has an LLM write tool descriptions, but every server starts disabled until its owner enables it, and description changes need owner approval.
