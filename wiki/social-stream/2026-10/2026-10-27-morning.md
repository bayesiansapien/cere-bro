- **Four Gemini agents beat Minecraft** ([@rohanpaul_ai](https://x.com/rohanpaul_ai/status/2114835672985113080), [paper](https://arxiv.org/abs/2610.22319)). A DeepMind paper (a DAIR pick, first seen here 10-17) gives four Gemini 4 Argon coding agents one goal, defeat the Ender Dragon, and a JavaScript library that maps code to game actions. Nobody assigned roles; the team organized itself through chat and shared notes. From a random Easy world they finished in 27 hours 14 minutes, writing 2,783 programs and dying 605 times. It is a single run, so the success rate is unknown. The takeaway for long tasks: try general coding agents with a plain API and shared memory before building custom planners.

- **LLMs cannot be random** ([@rohanpaul_ai](https://x.com/rohanpaul_ai/status/2114785180653437126), [paper](https://arxiv.org/abs/2604.06543)). A DeepMind paper asked Gemini, Qwen3 and OLMo to sample from simple distributions 1,024 times each. Every statistical test for matching the target odds failed, and temperature or top-p changes did not help; models keep landing on favorites like 7, 42 or answer C. Larger models do convert a supplied random number correctly. In a security game where truly random checks let attackers win 75% of the time, Gemini's choices let them win 96.6-99.9%. If an agent needs randomness, generate it in code.

- **Harness engineering, again (cluster of 3)** ([@omarsar0](https://x.com/omarsar0/status/2114915028797382967), [@haizhong_zheng](https://x.com/haizhong_zheng/status/2114769723879464983), [@0xShoopy](https://x.com/0xShoopy/status/2114790479028216132)). Elvis Saravia reposted HarnessMM, which stores an agent's settled actions in a decision graph and replays them when a guard holds, cutting a DeepSeek harness from 96k to 12k tokens per task while success rose from 71% to 86% ([paper](https://arxiv.org/abs/2610.32813)). Infini-AI Lab open-sourced Hermit, a harness-evolution framework that trains reusable adapters without touching the model or the harness. A thread summarized Google's guide to agents that run for days in six layers: a scheduler trigger, a server-owned runner, database-backed state, a resumable workflow that never reruns finished steps, a human approval gate, and idempotency guards so retries never charge twice. See [HarnessMM](../../agentic-systems/2026-10-27-harnessmm-decision-reuse.md).

- **Principia** ([@DongkiKim95](https://x.com/DongkiKim95/status/2114939639396290636), [paper](https://arxiv.org/abs/2610.32195)). KAIST's framework has an LLM compare related inputs and outcomes to form causal hypotheses, generalize recurring relationships into principles, then revise both as new observations arrive, all at test time. It targets the slow step in scientific discovery: turning observations into reusable rules.
