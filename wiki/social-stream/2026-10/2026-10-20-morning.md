- **FlashMap: speculative decoding with flow maps** ([@jeff_shen_](https://x.com/jeff_shen_/status/2112379880390131738); [paper](https://arxiv.org/abs/2610.24365)). Speculative decoding has a small drafter propose a block of tokens that the big model verifies in one pass. Block-diffusion drafters like DFlash write the block in one pass but predict each token independently. FlashMap conditions a flow-map language model on the target's hidden states, so it writes the whole block in one pass while modeling how the tokens depend on each other. Up to 6.1x lossless on Qwen3-8B and 7% more average speedup than a matched DFlash. See [speculative drafting](../../inference-efficiency/2026-10-20-speculative-drafting-dlite-ready-flashmap.md).

- **vLLM Speculators v0.9** ([@RedHat_AI](https://x.com/RedHat_AI/status/2112216200558104693); [release](https://github.com/vllm-project/speculators/releases/tag/v0.9.0)). The library that trains drafters for vLLM got a fused loss kernel (up to 2x faster forward passes on ~1B drafters) and an FP8 hidden-state backend that halves storage with no loss in drafter quality.

- **Where offloaded KV blocks live** ([@PyTorch](https://x.com/PyTorch/status/2112406775442124807)). - **DeepMind's Busy Beaver agent** ([@omarsar0](https://x.com/omarsar0/status/2112226024419365210); [paper page](https://academy.dair.ai/papers/at-the-limits-of-computability-steps-towards-autonomous-ai-discovery-on-the-busy-2610.22603)). A Gemini-based agent searched the BB(6) frontier of the Busy Beaver problem, picked its own Turing machines, found patterns in their execution traces, and proposed compact rules that summarize many steps. Each rule was proven in Lean, and only proven rules were kept. Eleven previously unresolved machines now have exact descriptions, though whether they halt is still open.

- **Reasoning models can control their CoT after all** ([@dair_ai](https://x.com/dair_ai/status/2112234077705433250); [paper](https://arxiv.org/abs/2610.23257)). Earlier tests put a constraint on the chain of thought in the user prompt and found models rarely followed it. Placed as a self-instruction inside the chain of thought, the constraint is followed far more often, and a generic reminder helps too. The catch: the authors show this control can be used to evade a CoT monitor. See [oversight shorts](../../responsible-ai/2026-10-20-cot-controllability-and-agent-oversight-shorts.md).

- **Agents for different parties never verify each other** ([@rohanpaul_ai](https://x.com/rohanpaul_ai/status/2112228442595013057)). Salesforce ran over 2,500 agent-to-agent sessions across 488 scenarios using Claude Code, Codex and Cursor in separate sandboxes and found 20 failure modes. No agent re-fetched a document to check a peer's claim. One $24,000 dispute settlement passed all 10 outcome checks while the vendor agent leaked confidential details. The advice: score each agent against the party it serves.

- **ProPerAgent: a harness for proactive assistants** ([@dair_ai](https://x.com/dair_ai/status/2112279124551328018)). Meta's harness decides when a wearable assistant should speak. It spots objects in view, retrieves personal memories from a graph, and runs a separate LLM check on whether the memories justify interrupting. Accuracy rises from at most 15% with standard memory to 38% with no weight changes. Removing the filter drops it to 24.0%, and unneeded interruptions fall to 15.3% vs 77-84% for standard RAG.
