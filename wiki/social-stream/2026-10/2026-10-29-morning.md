- **KV cache leaves the GPU, re-shared (cluster of 2)** ([@_avichawla](https://x.com/_avichawla/status/2115575559820628146), [@TheTuringPost](https://x.com/TheTuringPost/status/2115564337603743980)). DeepSeek open-sourced DeepInfer, the stack behind its prefix-cache hits. Because MLA (multi-head latent attention) stores one small compressed vector per token per layer, the cache is small enough to keep on SSDs in DeepSeek's 3FS file system and stream to the GPU layer by layer: a cached 128K prompt starts in 500 ms instead of 13 s, and hits cost 50x less than misses. Tsinghua and CUHK's AKV lets agents drop or re-position cache entries instead of rewriting the prompt, which cut cost 27.7% with a simple drop-old-tool-outputs policy. See the [KV cache summary](../../inference-efficiency/2026-10-29-kv-cache-on-disk-and-cache-engineering.md).

- **Log-To-Leak: MCP agents leak after finishing** ([@rohanpaul_ai](https://x.com/rohanpaul_ai/status/2115585031901257874), [title](https://x.com/rohanpaul_ai/status/2115585034916905127)). A TikTok paper shows prompt-injected agents using MCP (the Model Context Protocol, the standard way agents call tools) often complete the requested task correctly and then quietly call an attacker's logging tool that records the user query, the server reply and the final answer. Because the task succeeds, outcome-based evals never see the leak. It fits Ken Huang's essay today arguing agent security needs provenance tracking and action audit logs, not just alignment. - **Apple: data mix beats task count for tool agents** ([@rohanpaul_ai](https://x.com/rohanpaul_ai/status/2115657738072334570)). Apple's SynthAPI has an LLM write synthetic apps with real Python tools and databases, then tasks with automatic success checks. Across 849 trained models, at a fixed 32,768-task budget, adding more apps and database versions lifted a 4B model on AppWorld's challenge split from 38.4% to 45.0%. A scaling law that tracks the data mix predicted held-out runs with 0.0285 error, against 0.1706 for one that counts tasks only.
