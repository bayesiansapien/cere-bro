## Summary

No curated reposts came through this slot, so these 15 posts come from the Following feed, and the best item is a numerics paper. DeepMind's "A Fix for Softmax and Cross-Entropy" finds two rounding bugs in the standard kernels that cause loss spikes and push distilled students away from their teachers, and it fixes them without raising precision. The loudest cluster is harness engineering (cluster of 4): a recycled "End of Harness Engineering" thread, an Anthropic-engineer workshop pitch, a "27B model cracked self-improvement" thread and a Claude Code auto-config trick. The research behind them is real and already covered, but these threads are hype. ## Posts

- **A Fix for Softmax and Cross-Entropy** ([@askalphaxiv](https://x.com/askalphaxiv/status/2113885174673133971) · [paper](https://www.alphaxiv.org/abs/2610.31642)). Barron, Gnanapragasam and Tschannen (DeepMind) name two bugs. "Softmax Collapse" rounds the target logit's gradient to zero when one logit dominates. "Softmax Cancellation" leaves nonzero gradients when student and teacher logits are equal. The fix removes grokking loss spikes (94.3% to 100% in one setting) and stops students drifting from teachers, with no extra precision. It matters for distillation and low-precision training. See [knowledge distillation](../../inference-efficiency/knowledge-distillation.md).
- **EdgeRock-4B: fixed-size memory for long reasoning** ([@svpino](https://x.com/svpino/status/2113690674742849836)). An open text-and-image 4B model that keeps a window of recent tokens plus a learned, compressed summary, so memory stays flat as reasoning grows. Predictable memory means more requests per GPU. The costs are lossy recall and the need for a custom serving stack. It's a learned KV-eviction design, see [KV cache](../../inference-efficiency/kv-cache.md).
- **25 inference-engineering interview problems** ([@vishalsingh2972](https://x.com/vishalsingh2972/status/2113830444722741637)). The list covers sizing a 70B KV cache with GQA, PagedAttention, why FlashAttention is faster at the same math, continuous batching, chunked prefill, prefix caching with cache-aware routing, speculative decoding, FP8/INT4/NVFP4 and H100 vs B200. The engagement framing is bait, but the list itself is a good map of a serving stack. See [disaggregated serving](../../inference-efficiency/2026-09-15-disaggregated-serving-mooncake-distserve.md).
- **Harness hype threads (cluster of 4)** ([@virgilxbt](https://x.com/virgilxbt/status/2113750670545482170) · [@hayatomaruu](https://x.com/hayatomaruu/status/2113719510985269442) · [@thesupermannx](https://x.com/thesupermannx/status/2113642737757245649) · [@Sprytixl](https://x.com/Sprytixl/status/2113609423763468306)). - **macOS 27 ships a local LLM in Terminal** ([@dr_cintas](https://x.com/dr_cintas/status/2113756925124882770)). Apple's on-device model can be used via the `fm` CLI, with JSON schemas and an OpenAI-compatible `fm serve` endpoint. Each session is capped at 4,096 tokens shared between prompt and answer. It's free for summarizing and classifying, too small for code.
- **Udgam: one person, five open models** ([@Fintech03](https://x.com/Fintech03/status/2113872855343792353)). A chat model trained from scratch for $146, a 29.5MB Hindi speech-to-text model said to beat Whisper large-v3 on Hindi, and a 384M reasoning model trained on 17B tokens, all Apache-2.0 with public cost ledgers. The cheap-training receipts are the interesting part. Verify the benchmarks before trusting them.
- **LoRA and QLoRA, explained via matrix patterns** ([@dongxi_nlp](https://x.com/dongxi_nlp/status/2113918890753302818)). Part three of a Chinese post-training series. It ties rank, low-rank approximation and quantization to one idea: patterns in the weight matrix. A good primer. See [quantization](../../inference-efficiency/quantization.md).
