## Summary

The morning slot had no reposts and no tweets from tracked handles, so this synthesis reads the latest capture of the Following feed, which covers the US Wednesday afternoon and evening. The strongest signal is a cluster of about 8 posts on Nvidia's leadership crisis: the board met Wednesday night to consider removing Jensen Huang, and the same evening brought a new Commerce rule against remote access to Blackwell chips. A second cluster of 3 posts is decision models, after Google launched the Gemini Decisions API, a model that scores up to 1,000 yes/no, choice and rubric questions in one pass without generating text. A third cluster of 3 covers Anthropic's claim that Mythos ported Claude to AMD GPUs in three days, which the feed reads as a crack in Nvidia's CUDA moat. Agent Arena posted two cost-aware results: Claude Fable 5.2 at #1 with a wide lead, and Meta's Muse Ember as the cheapest capable agent model. Weight-space editing kept circulating, now as a propose-score-keep loop. Smaller items: Stanford opened its agent-engineering course, a Microsoft/Tsinghua paper found most GPU kernel library bugs live in builds and environments, and Berkeley proposed watermarks for detecting distillation.

- **Google launches the Gemini Decisions API (cluster of 3)** ([@VaibhavSisinty](https://x.com/VaibhavSisinty/status/2120600909336211491), [@omarsar0](https://x.com/omarsar0/status/2120589351264379268), [@rohanpaul_ai on cost routing](https://x.com/rohanpaul_ai/status/2120630771639820629)). Gemini Decision 1 does not write text. It scores options, with yes/no, multiple choice and rubric questions, up to 1,000 per request across text, images, audio, video and PDFs, in 150 to 250 ms at $0.10 per million input tokens and free output. The feed frames it as Google "coming for Jev", the startup that defined the category. Elvis Saravia plans to run it on his research benchmarks. A separate post shows the consumer version of the idea: a desktop video agent that checks each provider's price per render and routes every clip to the cheapest. Summary: [the decision-model wave](../../ai-routing/2026-11-12-gemini-decision-1-and-the-decision-model-wave.md).

- **Where GPU kernel libraries actually break** ([@rohanpaul_ai](https://x.com/rohanpaul_ai/status/2120626861760024693), [paper](https://arxiv.org/abs/2611.09280)). Microsoft and Tsinghua read 300 closed issues across seven libraries including FlashAttention, Triton and CUTLASS. 60.33% came from compilers, builds and runtime environments, 39.67% from kernel code, and 25.33% from version mismatches among drivers, CUDA, frameworks and packages.

- **Disaggregation as a conveyor belt** ([@not_ellington](https://x.com/not_ellington/status/2120628712253079982)). A short argument that disaggregated serving plus pipeline parallelism beats shuffling memory between GPUs: move the residual stream along stages that each hold the memory they need.

- **Distillation detection with watermarks (cluster of 2)** ([@hrshtv via Berkeley AI](https://x.com/berkeley_ai/status/2120590217627230463), [@sewon__min via Berkeley AI](https://x.com/berkeley_ai/status/2120590267501908344)).
