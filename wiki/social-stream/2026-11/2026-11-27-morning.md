## Summary

The morning slot had no curated reposts and no new saved posts over Thanksgiving, so this synthesis comes from the morning Following-feed capture, which carried the US Thanksgiving afternoon and evening. The strongest signal is a cluster of three on agent harnesses that do not improve themselves as much as claimed: Amazon's ARC-AGI-3 harness study, Microsoft's over-editing study, and UW and Microsoft's success-versus-failure memory paper. A second cluster of two pushed NVIDIA's model-driven context paper again, now with the headline number (GPT 6.1 Sol nearly tripling at a 32K budget). The standout single item is the Scale AI and Carnegie Mellon critic study: PPO beats GRPO at small RL batches and the two tie at large ones. Outside research, Deedy Das built a 3,533-Elo chess engine with coding agents for about $50, Sakana announced a 30B model that beats a 120B one, and OpenAI's voice model topped a live-call benchmark while human raters still preferred a human. Hype threads about "leaked" agent prompts and jailbreaks were loud and skippable.

## Posts

- **Self-built harnesses and agent edits, measured (cluster of 3)** ([@rohanpaul_ai](https://x.com/rohanpaul_ai/status/2126127228329300257), [ARC-AGI-3 paper](https://arxiv.org/abs/2610.30499); [@rohanpaul_ai](https://x.com/rohanpaul_ai/status/2126153340593844647), [over-edit paper](https://arxiv.org/abs/2611.34875); [@rohanpaul_ai](https://x.com/rohanpaul_ai/status/2126066219086475459), [DualPM paper](https://arxiv.org/abs/2611.33612)). Amazon had frontier models build a full ARC-AGI-3 harness (the program around the model that handles perception, memory, tools and retries), play five practice games, and revise the code twice. Scored on 20 unseen games, two revisions raised performance by only 2.80 points, with a confidence interval that crosses zero; just picking the best existing snapshot by practice score did better (4.53). Microsoft reverted every block of 7,660 agent patches and reran the tests: agent patches are 2.33x bigger mainly because they add tests (61%) and docs (13%), and agent code is at least as necessary as developers' (0.887 vs 0.864). UW and Microsoft found memories written from failures widen an agent's tool search, while memories from successes make it faster. See the [agent shorts summary](../../agentic-systems/2026-11-27-agent-shorts-overedit-rlcr-harness-memory.md).

- **NVIDIA: let models compact their own context (cluster of 2)** ([@rohanpaul_ai](https://x.com/rohanpaul_ai/status/2126118827264294915); [@omarsar0 repost](https://x.com/omarsar0/status/2126144118313398515), [paper](https://arxiv.org/abs/2611.34147)). Agent frameworks usually summarize history for the model when the window fills. NVIDIA gave models an API to decide when and what to compact. GPT 6.1 Sol nearly tripled at a 32K budget (21% to 56% on OfficeQA Pro v2), Kimi used up to 41% fewer input tokens, and reusing the KV cache (stored attention keys and values) of the unchanged suffix after an edit cut prefill by up to 15%. Models differ widely in when they compact. See the [summary](../../agentic-systems/2026-11-27-model-driven-context-management.md).

- **When a critic pays in RL** ([@rohanpaul_ai](https://x.com/rohanpaul_ai/status/2126032236487319905), [paper](https://arxiv.org/abs/2611.32013)). Scale AI and CMU ran more than 1,200 training runs comparing PPO (which trains a critic model to score each step) with GRPO (which scores each rollout against its group, no critic). PPO leads at small batch sizes; on terminal agents it led by up to 5.9 points at batches of 128 and 512, and everything tied within 0.6 points at 2,048. PPO at batch 128 matched GRPO at 512 for 91 versus 342 GPU-hours. See the [RL shorts summary](../../llms-foundation-models/2026-11-27-rl-signal-shorts-nopo-splice-cfsql-critic.md).

- **A $50 agent-built chess engine** ([@deedydas](https://x.com/deedydas/status/2126140365208224057), [repo](https://github.com/deedy/chess-chatarunga)). Deedy Das built Chatarunga, a zero-dependency Rust engine with an embedded NNUE (a small neural network that scores positions), rated about 3,533 and scoring 37% against Stockfish, using Fable, Neon and Astra plus Modal for about $50 of compute. His main lesson: verification loops are everything; define the minimum viable training run and what it should show before letting the model run long.

- **Hugging Face on running agent swarms at scale** ([@bookwormengr](https://x.com/bookwormengr/status/2125786730376921216), [report](https://huggingface.co/spaces/HuggingFaceSwarms/scaling-swarms)). Hugging Face published a report on keeping thousands of agents working toward one goal, and open-sourced Legion (a harness-agnostic framework to spawn thousands of agents from a laptop to a cluster) and Msgboard (a shared message board for agents and humans).

- **Sakana Namazu Small (30B)** ([@SakanaAILabs](https://x.com/SakanaAILabs/status/2125389733048291698), [blog](https://sakana.ai/namazu-small/#English)). Continued pre-training and post-training on NVIDIA's Nemotron 3 Nano base; Sakana says it beats the 4x larger Nemotron 3 Super (120B) on average across 25 benchmarks, with strengths in long-document reading and web search. On-prem details in December.

- **NVIDIA Auto Ontology** ([@thisdudelikesAI](https://x.com/thisdudelikesAI/status/2125898735867801998), [repo](https://github.com/NVIDIA/auto-ontology)). An open-source framework that builds a semantic layer from existing warehouse metadata, so an agent asked for "revenue last quarter" knows which team's definition to use and how tables join. The problem it targets is the query that runs cleanly and returns the wrong number.

- **Uber's 5,000-tool MCP gateway** ([@pvergadia](https://x.com/pvergadia/status/2126156378524045372)). Uber put 800+ MCP servers and 5,000+ tools behind one gateway: a crawler drafts tool definitions, agents search for tools instead of loading them all, and every call is checked, translated and trimmed. The X article body was not captured; click through to read.

- **GPT-Live-1.1 tops Jarvis Bench** ([@rohanpaul_ai](https://x.com/rohanpaul_ai/status/2126068055725965384)). OpenAI's voice model debuted first on naturalness (999 Elo), but blind raters scored a human agent 1,288. It hit 100% task success on live airline bookings with GPT 6.2 Sol as its backend, while raters judged Gemini 3.8 Live better at handling the call. The benchmark keeps naturalness, call handling and task success separate.

- **Chinese labs expect the gap to widen** ([@rohanpaul_ai](https://x.com/rohanpaul_ai/status/2126061649069281491)). A repost of The Information's report that Chinese labs are losing both rented Nvidia chips abroad and the ability to distill American models, and now expect the US lead to grow.
