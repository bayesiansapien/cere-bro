The strongest signal was the price of GPU generations: a Deutsche Bank estimate put GB300 capacity at about $13 an hour against $3.50 for H100, the same day Microsoft was reported switching off rented Oracle H100 servers. - **The GPU generation premium (cluster of 3)** ([@StockSavvyShay on Deutsche Bank](https://x.com/StockSavvyShay/status/2119051898930319409), [@rohanpaul_ai on Microsoft-Oracle](https://x.com/rohanpaul_ai/status/2118783864177148059), [@StockSavvyShay on IREN](https://x.com/StockSavvyShay/status/2118762700515983749)). - **Agent memory and "dreaming" (cluster of 4)** ([@AnthropicAI](https://x.com/AnthropicAI/status/2118814753154064501), [@omarsar0](https://x.com/omarsar0/status/2118838318180037041), [@hungryturbo](https://x.com/hungryturbo/status/2118874895237185734), [@Xudong07452910](https://x.com/Xudong07452910/status/2118893703850860912), [post](https://www.anthropic.com/research/components-of-agent-memory)). Anthropic's engineering post splits agent memory into layers. Raw transcripts stay as evidence, key lessons go into memory notes, and an offline "dreaming" pass rereads logs to fix mistakes, deduplicate and link notes into a wiki. A new session loads only a small index and fetches detail on demand. The Chinese threads stress that memory is not context compression: it persists across sessions and is mounted when needed. omarsar0 calls memory one of the biggest levers in a harness. See the [11-09 summary](../../agentic-systems/2026-11-09-anthropic-agent-memory-and-google-agent-distraction.md).
- **Harness over model (cluster of 3)** ([@Thom_Wolf](https://x.com/Thom_Wolf/status/2118863053001531676), [@garrytan](https://x.com/garrytan/status/2118920030243139596), [@omarsar0 on ReproBridge](https://x.com/omarsar0/status/2119085975880212842), [paper](https://arxiv.org/abs/2611.08452)). Hugging Face reports that the same open model gives very different results in different harnesses and is working on "harness adapters". Garry Tan removed his /investigate skill because Opus 5.5 does better without it, and argues for eval-driven loops that prune skills as models improve. Google's ReproBridge packages cleaned code, environment and launch scripts from one successful reproduction; the next agent's success rises from 76.4% to 92.6%, API spend drops 19.7%, and the best-to-worst model gap shrinks from 21.6 to 3.9 points. See the [summary](../../agentic-systems/2026-11-08-agent-benchmarks-and-research-shorts.md).
- **Agents as teammates** ([@omarsar0](https://x.com/omarsar0/status/2118833814839705786), [paper](https://arxiv.org/abs/2611.02633)). Stanford's Collaborative Intelligence Benchmark has 240 tasks from real records such as aviation accident reports, clinical cases and negotiations, scored only where a model can already solve the task alone. The best of 18 models scores 82.2. Every model loses 20 to 47 points once a teammate creates a problem, and under a pushy negotiating teammate they reach the best team deal only 14% of the time. The attached image is the paper's overview figure of the eight teamwork dimensions.
- **MCP agents rarely say a task is impossible** ([@dair_ai](https://x.com/dair_ai/status/2119083711522316490), [paper](https://arxiv.org/abs/2611.07689)). MCPHallu runs 358 tasks on 36 production MCP servers, each built to trigger one failure: branch collapse, unreachable goal, tool misuse or forgotten context. Across 14 frontier agents the mean score is 0.642. On unreachable goals only 23.2% of runs pass, because agents keep calling tools or claim success. A model's rank moves 6.9 of 13 places depending on failure type.
- **Poisoned fine-tuning data that looks normal** ([@rohanpaul_ai](https://x.com/rohanpaul_ai/status/2118810336673562807)). A UC Berkeley pipeline searches for small datasets that look like ordinary training data but raise a chosen behavior, such as recommending self-harm or resisting shutdown. It found 6,575 across 8 behaviors, and 72% induced the behavior in all 5 other models tested, including one 8x larger. ML researchers guessed the side effect only 63% of the time. See the [summary](../../responsible-ai/2026-11-08-jailbreaks-depend-on-pretraining-run.md).
- **Why a top-2 MoE can be slower** ([@DailyDoseOfDS_](https://x.com/DailyDoseOfDS_/status/2118999411254767695)). An explainer with a diagram tracing tokens from GPU 0: one stays local, one crosses NVLink to another GPU, one crosses the network to another server. Fewer FLOPs per token do not help when activations must travel and per-expert batches are small. See the [MoE routing summary](../../inference-efficiency/2026-11-07-moe-routing-strategies-for-serving.md).
- **OpenAI BioBasicsBench** ([@rohanpaul_ai](https://x.com/rohanpaul_ai/status/2118794080885051683), [@OpenAI](https://x.com/OpenAI/status/2118782708767965238)). 100 tasks from real experiments built with enzyme-design company Ligo: raw gels, colony plates, microscopy, sequencing reads and bench videos, graded with partial credit including for saying the evidence cannot support a conclusion. GPT-6 Astra earns 66.7% vs 43.8% for GPT-5.6 Sol, using about 4,704 output tokens per task, roughly half the older model's.
- **Google DeepMind and 1024-bit RSA** ([@GoogleDeepMind](https://x.com/GoogleDeepMind/status/2118755418675765656)). Human-guided agents uncovered two major weaknesses in legacy 1024-bit RSA systems. Only the announcement was captured.
- **A 355-weight multiplier** ([@deepaksinghml](https://x.com/deepaksinghml/status/2118411839038206329)). 4-digit multiplication is hard for trained transformers; prior work reached it by phasing out chain of thought or with a running-sum loss. An LLM wrote a transformer that does it with 355 hand-set weights, about 40,000x fewer than the trained state of the art, with no training.
