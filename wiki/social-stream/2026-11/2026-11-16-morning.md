- **Harnesses need boring deterministic parts (cluster of 4)** ([@omarsar0](https://x.com/omarsar0/status/2122035455793188980), [@omarsar0 follow-up](https://x.com/omarsar0/status/2122083635193098355), [@0x_kaize on Lauren Tan](https://x.com/0x_kaize/status/2121997657858281657), [@rohanpaul_ai](https://x.com/rohanpaul_ai/status/2122068216797434120)). Elvis Saravia says the best agent systems he has built or seen "involve lots of boring deterministic steps." Adding more LLM agents compounds errors, so you need classifiers, verifiers and evaluators in the loop. In a follow-up he says most current harnesses try to automate everything and invite more failures during long runs. Lauren Tan, who ships over 3,000 pull requests a month with agents, applies the same idea to mistakes. Each one goes through four questions: can the code be redesigned so the mistake is impossible, can a lint rule or type catch it, can the agent catch it by running its own checks, and does it really need a written rule. A new AGENTS.md line is the last resort, not the default. Rohan Paul's repost of the Northwestern and Google paper (agent harnesses that improve on new tasks without answer keys, by testing each proposed edit on real runs) is the research version of the same discipline. See [agent harness engineering](../../agentic-systems/agent-harness-engineering.md).

- **Agents that debug chips through SQL** ([@rohanpaul_ai](https://x.com/rohanpaul_ai/status/2122114049353908599), [paper](https://arxiv.org/abs/2610.06790)). Chip simulations log every signal change, and the waveform dumps can exceed 10 GB of text that engineers still read by hand. The paper notes about 74.6% of LLM-for-EDA (electronic design automation) work targets RTL code generation, not this verification step. BTTF converts the dumps into a compact SQLite database, and a team of agents turns English questions into SQL, checks design rules and audits each answer. It gets 95.33% of 150 expert-labelled questions right with Gemini 2.5 Pro. The multi-agent split scores 17.3% higher on a quality audit than one agent at 1.96x the latency. The takeaway generalizes: when the data will never fit in context, give the agent a query interface. See the [BTTF summary](../../hardware/2026-11-16-bttf-agentic-chip-verification.md).

- **Sinkhorn balancing, a 1963 result still everywhere** ([@docmilanfar](https://x.com/docmilanfar/status/2122174674096501109)). Peyman Milanfar on Sinkhorn's algorithm: alternately normalize a non-negative matrix's rows and columns until it is doubly stochastic. It solves entropic optimal transport and shows up in PageRank, SLAM, multi-omics alignment and market design. It is also the routine behind balanced token-to-expert assignment in some MoE (mixture-of-experts) routers.
