## Posts

- **Harness and memory engineering (cluster of 3)** ([@rohanpaul_ai on Harness²](https://x.com/rohanpaul_ai/status/2121757204810469793), [paper](https://arxiv.org/abs/2610.14224), [@omarsar0 on MemCredit](https://x.com/omarsar0/status/2121610612040220832), [paper](https://arxiv.org/abs/2611.15600), [@taha_rafiq](https://x.com/taha_rafiq/status/2121479924276244979)). Harness² (Northwestern and Google) lets an agent's harness (its prompts, tools, skills and memory) improve on new tasks with no answer key. An editor model proposes fixes, the task reruns, and only edits that change behavior on real runs are kept, with lessons stored in a library for the next task. One improvement step raised GLM-5's WorkBuddy-Bench score by 11.5 points, past Gemini 3.5 Flash on its stock harness. Editing without those test runs dropped coding scores from 73.4 to 63.2. MemCredit measures each memory by removing it and checking whether the agent's next action changes. Most memories change nothing, and the learned selector reaches 86.6% on ALFWorld against 65.7% for BM25, with 74.5% fewer memory tokens. Taha Rafiq's X article distills years of building agents at Meta into four rules: build verification first, read agent traces, don't over-engineer, and build feedback loops into the product. See [MemCredit](../../agentic-systems/2026-11-15-memcredit-decision-utility-memory.md) and [agent harness engineering](../../agentic-systems/agent-harness-engineering.md).

- **e-means: k-means rebuilt for GPUs (cluster of 2)** ([@akshay_pachaar](https://x.com/akshay_pachaar/status/2121609389450854860), [@TheTuringPost](https://x.com/TheTuringPost/status/2121725370135450083), [paper](https://arxiv.org/abs/2611.09501)). Classic k-means has to scan the whole dataset before it moves any cluster center. Meta's e-means moves each center by an exponential moving average over mini-batches. It splits crowded clusters to revive dead ones and sets batch and step sizes from scaling laws, so there is nothing to tune. It reaches 25 epochs' worth of k-means loss in about 2 epochs, 10-45x faster on GPUs. It matters for vector quantization, retrieval indexes and data deduplication.

- **Dory1.0-4B explainer** ([@noahatwhere](https://x.com/noahatwhere/status/2121779062016446910), [paper](https://arxiv.org/abs/2611.03998)). A Chinese-language walkthrough of NVIDIA's looped transformer, a model that reuses one middle block of layers several times so depth grows without new weights. The middle block runs 1-4 times, giving 72 to 192 effective layers from 4B parameters, and the input block's hidden state is re-injected with L2 normalization before each loop. SWE-bench Verified goes from 50.3% at one loop to 61.8% at four, and four loops write 1.3-2.5x fewer output tokens on agentic tasks. See [looped transformers](../../llms-foundation-models/looped-transformers.md).

- **When Rounding Breaks Machine Learning** ([@ChrSzegedy RT of @srush_nlp](https://x.com/ChrSzegedy/status/2121666289471299904), [post](https://www.robertj1.com/ai4science/rounding-bugs-in-ml-formulas/)). Robert Joseph George and Sasha Rush use FloatLib, a Lean library that models floating-point arithmetic at any precision and proves error bounds. They swept 154 operators across seven libraries and about 780 million outputs. It started with a softmax whose float32 target gradient came out exactly zero even though the true value was representable. The sweep found bugs in PyTorch, JAX, TensorFlow Probability, diffusers, PyTorch Geometric and xLSTM, several never reported. See [the wiki summary](../../inference-efficiency/2026-11-15-rounding-breaks-ml-floatlib.md).

- **Against All Likelihood (cluster of 2)** ([@dair_ai](https://x.com/dair_ai/status/2121679587633746243), [@rohanpaul_ai](https://x.com/rohanpaul_ai/status/2121715777548239060), [paper](https://arxiv.org/abs/2611.09385)). A Meta position essay. Models trained by maximum likelihood learn what is common, so repeated falsehoods become probable and rare truths get discounted. It proposes treating a claim as true if it survives relevant changes of viewpoint. In practice, the model answers as several personas (say, three medical specialists), keeps what all answers share, and abstains if nothing is shared. Its sharpest worked example: on one binary case, a loss of 0.67 means 100% accuracy while a nearly equal 0.71 means 0%. No experiments. See [the wiki summary](../../responsible-ai/2026-11-15-metapi-and-against-all-likelihood.md).

- **Weight-Space Reading** ([@crazyMLguy](https://x.com/crazyMLguy/status/2121773683924668808), [repo](https://github.com/suayptalha/wsr)). Can an LLM predict what a weight edit will do to another model without running it? Qwen 27B with direct weight access predicted subtle edit effects at 73% balanced accuracy, against 57.8% from text descriptions. On Muse-30B, 34 edits and 6 no-op controls produced no detectable change, yet agents often predicted one. So false positives are the open problem. Models reading their own weights showed no clear advantage.
