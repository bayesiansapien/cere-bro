- **A Mixture of Experts handbook that goes past the usual hand-wave** ([@techNmak](https://x.com/techNmak/status/2099761843141275795)). MoE means the feed-forward block of a transformer becomes a bank of expert sub-networks and a router picks a small subset per token, which is how a model can carry huge total parameters while activating few. The handbook covers the parts most explainers drop: router logits, top-k selection, load balancing, capacity limits and token dropping, router z-loss, dropless execution, total versus active parameters, and expert parallelism, worked against Mixtral, DeepSeek-V3 and Qwen3.

- **A step-by-step roadmap for becoming an inference optimization engineer** ([@ashishllm](https://x.com/ashishllm/status/2099411773858484668)). It is a decent index of what the wiki's [KV cache](../../inference-efficiency/kv-cache.md) and [quantization](../../inference-efficiency/quantization.md) pages cover in depth.

- **Serving 100 fine-tuned models on one GPU, explained end to end** ([@_avichawla](https://x.com/_avichawla/status/2099772866225148024)). - **Proteus: a fixed-size memory should not expose all its capacity at token 1** ([@reza_byt](https://x.com/reza_byt/status/2099556816095007144)). This is the slot's one real architecture result. Linear-time attention swaps the growing KV cache for a fixed-size recurrent state, which is why it scales, but that state saturates as context grows. The diagnosis is sharp: early tokens face no pressure to compress, so they consume far more of the state than they need, and later tokens inherit a state that is already full. Proteus partitions the memory into blocks and unlocks them one at a time as context advances, gating both reads and writes so locked blocks are neither retrieved from nor written to. The state never grows, only the live fraction changes, so it costs nothing extra. Gains are small on standard language modeling (+0.37 to 1.05 average accuracy) and large where it should matter, up to +8.4 needle-in-a-haystack points at twice the training context length. See [attention mechanisms](../../llms-foundation-models/attention-mechanisms.md).

- **260 controlled experiments on when multi-agent systems actually help, and the average is negative** ([@N01ennn](https://x.com/N01ennn/status/2099817536313266325)). - **Microsoft's LoopsBench argues the failure point is the loop, not the patch** ([@marfinxx](https://x.com/marfinxx/status/2099830820466831586) · related: [@rohanpaul_ai](https://x.com/rohanpaul_ai/status/2099778944405049433)). 112 multi-step tasks across 5,300+ development units, with Claude Opus 4.7 inside Claude Code resolving 25% of authentic repositories. - **FlashREINFORCE asks whether long-horizon agentic RL needs rollout groups at all** ([@BhavinJawade](https://x.com/BhavinJawade/status/2099606015331447255)). In long-horizon agentic RL that gets expensive and slow, because some agents finish fast and others make many tool calls, so the group stalls on the straggler. - **Latents have algebra and text does not** ([@aimalysheva](https://x.com/aimalysheva/status/2099607620864835935)). The usual argument for passing hidden states between models instead of tokens is bandwidth: a model computes around a million numbers to pick one token and only the token survives. The sharper argument here is that a tensor supports operations a paragraph cannot. Averaging two hidden states is defined and returns a valid hidden state. Projection works, and SVCCA showed a 512-neuron layer does its job on about 25 directions, so you can discard most of a representation and keep the computation. And a continuous reasoning state can be moved by gradient toward an objective, where with tokens the only move is to sample again and compare.
