<h4>Your agent would cost 260% more without the cache</h4>
<p>Arena analyzed over 26K Agent Arena sessions (Sept 12 to Oct 23) across 30 agents from 13 labs. Prompt caching (reusing the already-processed prefix of a conversation at a steep discount) is what keeps agent bills sane. Billed at full input price, a typical task on a top-10 agent would cost 3.6x more; a Claude Fable 5.1 task goes from $7.44 to about $27. ### Decoding and local serving get cheaper

<div class="mz-feed">

<div class="mz-card video">

<span class="mz-card-badge">Repo + demo · speculative decoding</span>
<h4>DFlash + Weaver: 7.5 tokens per forward pass on a Mac</h4>
<p>Speculative decoding lets a cheap drafter guess several tokens and the big model check them all in one pass. Parallel drafters like DFlash guess every position at once, but each guess is blind to the others, so one early miss throws away the rest. Weaver is a single Transformer layer on top of DFlash that picks among its top candidates left to right, grows a tree of likely continuations, and lets the main model verify the whole tree in one pass. On Qwen3.5 9B on an M5 MacBook Pro, the same prompt took 42s plain, 30s with regular speculation and 11s with Weaver; the paper reports 4x on B200 across chat, math and code. Mirai open-sourced it in uzu, its Apple Silicon engine. Memory-bound local decoding is exactly where more accepted tokens per pass pays off.</p>

<h4>tiny-llm: build a mini vLLM on a Mac</h4>
<p>An open four-week course that has you build a vLLM-style serving engine around Qwen3 on Apple Silicon. You start with a naive transformer, then fix its performance problems in order: add a KV cache (stored attention keys and values so old tokens are not recomputed), keep 4-bit packed weights to save memory bandwidth, write Metal kernels with fused RMSNorm, RoPE and SwiGLU, then add continuous batching, chunked prefill and paged KV storage. The last week wraps it in a small coding-agent harness. It crossed the feed twice today from unrelated accounts, a clean map of where serving cost actually goes.</p>

<h4>Nemotron 3.5 Super and Lightning</h4>
<p>NVIDIA's open hybrid Mamba-Transformer MoE family (MoE, mixture-of-experts: each token only uses a few sub-networks). Super is 120B total with 12B active and handles text, images and video; Lightning is 30B with 3B active. DAIR picked it too, so it is cross-source.</p>

### Agents as attack surface, persuaders and researchers

<div class="mz-feed">

<div class="mz-card">
<a class="mz-card-thumb" href="https://x.com/omarsar0/status/2116183621157736540"><img src="https://pbs.twimg.com/media/HV4xycVbsAAUgO9.jpg" alt="" loading="lazy" referrerpolicy="no-referrer"/></a>
<div class="mz-card-body">
<span class="mz-card-badge paper">Paper · agent security</span>
<h4>Agentic backdoors via pretraining poisoning</h4>
<p>Anthropic Fellows with Carlini and colleagues pretrained Qwen3 models from scratch (0.6B, 1.7B, 4B), poisoned 0.1% of the corpus, then post-trained each into a CLI agent with a clean pipeline. The backdoor survived SFT, DPO and tool-use RL, and on the 4B model the agent ran the attacker's command on about 92% of triggered prompts. The trigger can be an ordinary file path in the user's own request, and success grows with scale. Even at 0.0005% poison (about 2,500 documents in 100B tokens) it fired 1.4% of the time. Post-training does not wash out what pretraining planted.</p>

<h4>How AI agents shape experts' judgment calls</h4>
<p>Anthropic gave 50 analysts a Claude Code agent with a hidden lean on four analytical choices. Analysts followed the lean 86% of the time against a 50% chance baseline. Those who had written down their own view dropped it 60% of the time when the agent disagreed, versus 6% when it agreed, and 77% reused the agent's arguments while only 15% credited it. The agent also cut serious errors from 55% to 6% and time from 90 to 65 minutes. Anthropic flags one task, one model and a deliberately strong lean.</p>

<span class="mz-card-badge paper">Paper · research agents</span>
<h4>rTaste: do research agents have taste?</h4>
<p>Six frontier models read seven recent NLP papers and proposed minimum viable experiments, forecast which would pass and ranked them. A separate executor then ran every one, including those ranked last, and three model auditors judged the results. Of 415 experiments, 194 were sound, valuable and new, but only 73 also went beyond the seed paper. Agents' first choices beat a random pick yet not the experiment written first, their forecasts were no better than a fresh model reading only the paper, and agent teams cost more with no clear gain. Generation is cheap and decent; selection is where autoresearch still fails. DAIR picked it as well.</p>
