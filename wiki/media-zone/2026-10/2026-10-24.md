### Attention as routing and compression

<div class="dg-title">Every efficient attention picks one of two moves</div>

<span class="mz-card-badge paper">Paper · efficient attention taxonomy</span>
<h4>MiTA: attention is a temporary MLP, so route it or shrink it</h4>
<p>Self-attention can be read as a two-layer MLP whose weights are the keys and values, built fresh for every input, with softmax as the activation. Its hidden width equals the sequence length, which is why it gets more expressive and more expensive as context grows. The paper sorts efficient attention into a five-axis taxonomy where every method either routes tokens to part of that MLP (MoE attention, top-k, sparse selection) or compresses it (linear attention). MiTA does both: a few landmark queries gather top-k key-value pairs as flexible routed experts, plus a narrow shared expert. Tests are vision-only so far, and an emergent token-pruning effect appears for free. A Chinese-language thread that carried it framed DSA-style sparse attention as plain MoE routing.</p>

<span class="mz-card-badge">Explainer · KV cache quantization</span>
<h4>Six ways to shrink the KV cache, and why weight quant doesn't</h4>
<p>Quantizing weights leaves the KV cache (the stored keys and values of past tokens) at 16 bits, and that cache grows with context and concurrency. The thread walks through FP8 caches, INT8/INT4, scale granularity, KIVI (keys grouped per channel, values per token, usable at 2 bits without fine-tuning), mixed precision that keeps recent tokens sharp, and outlier-aware schemes like KVQuant. Its key caveat matches the MiniMax KV4 result from the 10-23 feed: a smaller cache fits more requests but does not guarantee faster decode, so always measure quality and latency against an unquantized cache.</p>

<span class="mz-card-badge">Model release · Tencent</span>
<h4>Hy-Nomas: a world model that lives in its KV cache</h4>
<p>Tencent's open interactive video world model generates one segment at a time. A persistent KV cache carries the world between segments, and causal attention across segments means the future is never needed. The single-RTX-4090 recipe is a compression stack in miniature: INT8 diffusion weights, an INT8 KV cache, an FP8 decoder, CPU offload, and a bounded 18-frame history window on GPU with older frames archived to CPU. Distilled to 8 denoising steps at 720p, 24 FPS. Vision is not your core beat, but the bounded-cache-plus-archive pattern is the same one long-context LLM serving uses.</p>

### Harnesses that learn, and proving the learning was real

<div class="mz-feed">

<div class="mz-card">
<div class="mz-card-body">
<span class="mz-card-badge paper">Survey · harness self-evolution</span>
<h4>Harness-RSI: 66 pages on agents that improve without new weights</h4>
<p>A Zhongguancun Academy and USTC survey maps how agents turn experience into persistent prompts, memory, skills, workflows and finally executable code, with 179 papers and a bilingual reading list. The part practitioners are quoting is its eval discipline: when an agent edits prompts, skills and code at once and the score rises, you must show which change took effect, that it caused the gain, and that the gain holds on a new task. Fail any one and the improvement is not real. That is the same attribution problem the MemoryTax paper raised on 10-23, when designed memory turned out to help only weak models.</p>

<h4>Beacon: one correction, remembered by every agent</h4>
<p>Asymptote Labs' open-source Beacon records agent sessions across 20+ harnesses (Claude Code, Codex, Cursor, OpenCode). ### Instructions that don't hold

<div class="mz-feed">

<div class="mz-card">
<div class="mz-card-body">
<span class="mz-card-badge paper">Thread + papers · negation</span>
<h4>"Don't delete the database" is a weak instruction</h4>
<p>Margaret Mitchell's thread ties two papers to real incidents where coding agents wiped data. One shows inverse scaling on negated prompts: bigger models do worse when the task says "not". The other (2601.08070) finds that violation probability follows a tight logistic curve in how much the model already wants to emit the forbidden thing, and that the suppression signal is 4.4x weaker in failures. Gary Marcus amplified it. The practical read: guard destructive actions in the harness (permissions, gates), not in prose.</p>
