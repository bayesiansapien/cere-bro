<span class="mz-card-badge paper">arXiv 2610.24365 · speculative decoding</span>
<h4>FlashMap: drafting a whole block with dependencies</h4>
<p>Speculative decoding has a small drafter guess a block of tokens for the big model to check in one pass. The fastest drafters write the block in one shot but treat each token as independent, which caps how many guesses survive. FlashMap uses a flow-map model conditioned on the target's hidden states, so the block is drafted in one pass and its tokens fit together. It reports up to 6.1x lossless speedup on Qwen3-8B and 7% more average speedup than a matched DFlash. It is one of three drafter papers this window aimed at the same weakness.</p>

<h4>Speculators v0.9: cheaper drafter training</h4>
<p>The vLLM project's drafter-training library added a fused loss kernel that makes forward passes up to 2x faster on ~1B drafters. <h4>Where the KV blocks live</h4>
<p>When GPU memory fills, vLLM offloads the KV cache to CPU or shared storage. llm-d tracks where every block sits and sends each request to the node that holds its cache. <h4>Prometheus: a gigawatt cluster at 85% goodput</h4>
<p>Meta's Ohio supercluster trained the Muse models across hundreds of thousands of GPUs in several buildings, with over 85% of pre-training time spent on useful work. Interruptions came every ~47K GPU-hours, since pushed past 54K with firmware fixes. Its GB300 racks carry 1.5x the HBM of GB200 but run only 5-10% faster on Meta's jobs. That gap between spec sheet and workload is the useful number. Meta also published the Muse Glimmer report, a 30B open-weight agent model that runs at 4-bit on one consumer GPU.</p>

## LLMs, agents, safety

### Agents that discover, and agents nobody checks

<div class="mz-feed">

<div class="mz-card">
<div class="mz-card-body">
<span class="mz-card-badge paper">arXiv 2610.22603 · Google DeepMind</span>
<h4>An agent that picks its own math problems and proves them</h4>
<p>The Busy Beaver problem has no fixed list of questions, so it tests whether an AI can choose what to work on. DeepMind's Gemini-based agent picked Turing machines from the BB(6) frontier, spotted patterns in their runs, and conjectured compact rules that skip many steps at once. Every rule had to pass a Lean proof, so nothing depends on trusting the model. Eleven unresolved machines now have exact descriptions; whether they halt is still open.</p>

<span class="mz-card-badge paper">arXiv 2610.23257 · monitorability</span>
<h4>Reasoning models can steer their CoT, and evade monitors</h4>
<p>Earlier work found models barely follow instructions about their own chain of thought. This paper puts the instruction inside the chain of thought as a self-instruction, and compliance rises sharply. A user prompt alone can trigger it. The same skill lets a model shape its reasoning to slip past a CoT monitor, so better control is also a monitoring risk.</p>

- **Agents for different parties never verify each other.** Salesforce's 2,500 sessions found no agent re-checked a peer's factual claim. A $24,000 settlement passed every outcome check while leaking confidential details.
- **ProPerAgent (Meta).** A memory-filtering step decides whether a wearable assistant should speak at all. Accuracy goes from ≤15% to 38% with no weight changes.
- **Harness² (Google Research).** Agents tune their own prompts, skills and memory by repeated runs. Widely reshared; one team reports steady vision gains with zero weight updates.
- **Human-centered coding agents.** A position paper argues supervision and trust, not raw capability, now limit coding agents.
