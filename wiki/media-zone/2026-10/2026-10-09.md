# Media Zone | 2026-10-09

> The US Thursday's conversation was about cost, through routing and through reused state. Jev-style decision models (pick an option, return a probability, never generate prose) went open, local and cheap within a day, and Claude Code's advisor mode moved routing inside the harness. Late in the US day, NVIDIA showed Dynamo routing agent requests by session so the KV cache stays warm through tool waits. A component-level harness (HERMES) lifted one model from 6.5% to 31.0% without touching its weights. The cost optimization angle runs through both: fewer frontier calls per decision, and fewer recomputed tokens per turn.

### Serving agents: the KV cache follows the session

<span class="mz-card-badge">Engineering blog · the day's top KV-cache artifact</span>
<h4>Session-aware agentic inference with NVIDIA Dynamo</h4>
<p>Agent sessions open with a huge prefill, resend their context every turn, fan out into subagents, and spend most of their time waiting on tools while the KV cache (the stored attention state) sits on the GPU. Dynamo now tags requests with a session ID; Claude Code, Codex and OpenCode headers map to it with no setup. On top: routing that pins a session to its warm worker, backpressure at tool boundaries so waiting sessions are not evicted, an indexer for reusable cache in external stores, and a proposed KvHint API so the harness states cache intent while vLLM or SGLang execute it. Traces replay without prompt text, so cache policies can be backtested. It is the serving-side fix for the prefix cache a router loses when it switches models.</p>

<h4>Laya: an Apache-2.0, local alternative to Jev</h4>
<p>Laya answers typed questions over unstructured state by scoring options, not generating text. It first picks an English or multilingual checkpoint in plain Python (a router before the model). Each answer option gets a [MASK] marker, a bidirectional encoder plus small head scores them, and softmax gives a distribution. All questions batch into one call. One test put it near 35 ms on a local GPU against roughly 380 ms for hosted Jev. The catch: Jev is zero-shot, Laya needs fine-tuning and calibration on your answer set, with uncertain cases sent to a bigger model.</p>

## LLMs, agents, safety

### Harnesses vs training: who improves the agent?

<div class="mz-feed">

<div class="mz-card">
<div class="mz-card-body">
<span class="mz-card-badge paper">Paper · the day's most-shared harness result</span>
<h4>HERMES: give every repo component its own resident model</h4>
<p>UIUC's Dev-Primitives pair each repository artifact with a resident LLM that knows its own code and dependencies, so components can reason, message each other and patch themselves. HERMES wakes only the components a task needs and maps test failures back to the ones that must change, which avoids the ever-growing transcript that long coding runs suffer. Same model and effort setting: GPT-5.6 Sol on whole-repo migration goes from 6.5% to 31.0% when Codex's harness is replaced. With strong activation and diagnosis models, Qwen3-8B components get within 4.5 points of an all-frontier setup at 26.2% lower Terminal-Bench cost.</p>

<h4>VERA: alternate training and skill edits</h4>
<p>VERA turns benchmarks into 9,000+ restartable sandboxes where every step of a long workflow is scored against real files and logs.
